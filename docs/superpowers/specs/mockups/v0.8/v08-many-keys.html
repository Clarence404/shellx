规则总结

0 个：无 chips · 只有"浏览" · 认证方式默认落"密码"
1–4 个:chips 行内直选（现设计不变）· 默认预选最优（ED25519 > RSA-4096 > 其它）
5 个及以上:自动切成下拉选择器 · 搜索过滤 · ED25519 排前 · 弱密钥（RSA-1024 / DSA）标 ⚠ 置灰弱化

识别逻辑：扫 ~/.ssh 下有配对 .pub 的私钥文件 + 常见命名（id_*、*.pem），读文件头判断类型 —— 不解密、不读私钥体。
