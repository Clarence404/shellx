v0.9 时这个表单再往下长两段：连接模式（Term+Tun / 仅 Tunnels / 仅 Term）、环境标签（TEST/STAGING/PROD）、端口转发规则列表。到时候表单改成左右两栏或分组折叠——v0.8 先不动

设计决策说明

  • 不做 tab、不做向导 —— 字段总数 v0.8 也就 7 个，单列扫下来 10 秒。tab 是 v0.9 加了转发规则之后再考虑的事
  • Host · Port · Username 合并一行 —— 三个字段逻辑上是一体的（`user@host:port`），合并后表单高度和现在打平，放下了新增的认证分段
  • 认证方式默认"密钥文件"还是"密码"？ —— 我建议：检测到 ~/.ssh 里有密钥就默认"密钥文件"并预选最优的（ed25519 > rsa），否则默认"密码"。对你这样的用户零点击，对没密钥的小白也不添乱
  • 密钥自动发现只在打开表单时扫一次 ~/.ssh（只列文件名，不读私钥内容），有"重新扫描"按钮手动刷新。不做后台常驻扫描
  • Edit 模式同样布局 —— passphrase 占位符显示"留空保持不变"，多一个"忘掉已存的 passphrase"复选（对齐现有密码的处理方式）
  • Quick connect（不勾 Save this host）同样可用密钥 —— 只是 passphrase 不落 keychain，仅本次会话使用
