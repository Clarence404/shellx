设计要点

  1. Activity tab 里加 "Tunnels" 页：和 Terminal / Files 并列，数字标当前活跃 tunnel 数，绿点=全通
  2. 每条 tunnel 一行：状态点（绿=活跃 · 黄=重连中 · 红=挂了）· 标签 · 本地端口 → 远端 · 一键复制端口 / 连接串 / 打开浏览器
  3. 环境标签驱动视觉：TEST 绿边 · STAGING 蓝边 · PROD 红边 + 顶部一条红警示条，危险按钮（复制连接串）也变红加 ⚠
  4. 生产环境二次确认：弹框列出将要建立的 3 条 tunnel 让你复盘，可勾"本次会话不再提醒"
  5. tunnel 挂了自动重连：图 ② 里第三条就是"探活失败 · 自动重连中"状态，用户手动"立即重试"也行
  6. HTTP tunnel 特殊按钮：RabbitMQ Web / Grafana / Kibana 这类，识别到 HTTP 就多一个"在浏览器打开"按钮
