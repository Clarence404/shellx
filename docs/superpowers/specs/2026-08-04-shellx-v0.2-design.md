## 1. 概述

v0.2 把 shellx 从"能连一台机的演示版"变成"日常好用的产品原型"。三个主线：

- **多 tab** —— 同时开多个 SSH 会话，独立运行、独立关闭
- **连接管理器** —— 保存主机（label / host / port / user）到本地 SQLite，密码走 OS Keychain
- **UI polish** —— 换掉 emoji 图标（Lucide）、重做空状态和品牌 wordmark、终端字体和 ANSI 配色一体化

**不做**：SSH 公钥认证、host-key 验证、`Protocol` trait 抽取、Light 主题、SFTP / FTP。这些留给 v0.3+ 各自的里程碑。

## 3. 数据模型

### 3.1 存储位置

沿用 v0.1 定义的跨平台配置目录（`directories` crate）：

- Windows：`%APPDATA%\shellx\`
- macOS：`~/Library/Application Support/shellx/`
- Linux：`~/.config/shellx/`

首次启动时如目录不存在自动创建，权限 0700（Windows 用户默认 ACL）。

### 3.2 SQLite Schema (`hosts.db`)

```sql
CREATE TABLE hosts (
  id TEXT PRIMARY KEY,               -- uuid v4
  label TEXT NOT NULL,               -- 用户可见名（允许重复）
  host TEXT NOT NULL,                -- ip / hostname
  port INTEGER NOT NULL DEFAULT 22,
  username TEXT NOT NULL,
  notes TEXT,                        -- 可空，v0.2 UI 上不展示
  created_at INTEGER NOT NULL,       -- unix ms
  last_connected_at INTEGER,         -- unix ms；null = 从未连过
  sort_order INTEGER NOT NULL        -- 手动排序初值 = created_at（保证插入顺序稳定），drag 排序留 v0.3
);

CREATE INDEX idx_hosts_sort_order ON hosts(sort_order);
```

数据库通过 `rusqlite`（bundled sqlite3）直连，无 ORM。所有 CRUD 走一个 Rust 模块 `src-tauri/src/store/hosts.rs`，暴露 `list() / get(id) / insert(...) / update(...) / delete(id) / touch_last_connected(id)`。

**Migration 策略**：v0.2 是首次引入数据库；启动时如 `hosts.db` 不存在则用 `include_str!("schema.sql")` 建表。未来 v0.3 起需要 schema 版本表 + migration 目录，v0.2 先不做。

### 3.3 密码存储：OS Keychain

- Crate：`keyring = "3"`（跨平台抽象 Win Credential Manager / macOS Keychain / Linux Secret Service）
- Service：常量字符串 `"shellx"`
- Account：**host UUID**（保证 host label 改名不影响密码定位）
- 写入时机：ConnectDialog 提交且 "Save this host" 勾选、"Remember password" 勾选、且密码非空
- 读取时机：从 drawer / ⌘K / tab-bar 触发连接、且 keychain 里有对应 UUID 的项
- 删除时机：`delete host` 时同步 `keyring::delete_password`
- SQLite **绝不存密码**（也不存加密后的密码，杜绝一份数据两地状态）

### 3.4 Linux Keychain 降级

启动时探测 `keyring::Entry::new("shellx", "__probe__")` + set/get/delete "1" 的往返，探测成功一次就永久标记 `keychain_available: true`（内存状态，不落盘）。

失败时：
- ConnectDialog 里 "Remember password" 复选框**默认灰置**，旁边小字 "Password storage unavailable on this system"
- "Save this host" 仍可用（保存 label/host/port/user 到 SQLite），连接时每次弹密码框
- `--verbose` 日志里输出探测失败的原因（用户能自己 debug）

### 4.1 图标：Lucide 替换 emoji

Stroke width 1.8，24×24 viewBox，18×18 实际渲染。激活项背景 `--accent` 紫，图标色 `--text-on-accent` 白。

### 4.2 Drawer（Hosts 视图，紧凑单行）

```
┌────────────────────────────┐
│ HOSTS                      │  ← 10px letter-spacing 1px 小标签
│                            │
│ ● prod-1              ⋯   │  ← 单行；bullet 6px 圆点，实心紫=已连接，
│   db-master           ⋯   │     30% 透明=未连接。hover 显示右侧 ⋯，
│   stage-web           ⋯   │     点击整行 = 连接，右键 = 菜单
│ ● home-nas            ⋯   │
│   ...                      │
│                            │
│ [＋ New connection]        │  ← accent-fade 背景，accent 边框
└────────────────────────────┘
```

**行为**：
- 点整行触发 connect（读取 keychain 密码，无则弹 password prompt）
- 右键 / hover-⋯ 弹菜单：**Connect** · **Edit** · **Duplicate** · **Delete**（Delete 二次确认）
- 空列表时不显示"No hosts yet"文字，只显示底部 New connection 按钮
- 排序：`ORDER BY sort_order ASC`（v0.2 = 按创建时间）

**Bullet 状态点（g 项）**：Zustand 的 `useSessions` store 增加派生 selector `hostIsConnected(hostId): boolean`——遍历 sessions，看有没有一个 session 的 `host_id === hostId` 且未关闭。Drawer 组件订阅这个 selector。

### 4.3 ConnectDialog 改造

新增字段：**Label**（顶部第一个，`useEffect` 里 `if (label === "") setLabel(\`\${username}@\${host}\`)` 自动填充）。

新增复选框：
- **Save this host**（默认勾选）—— 保存到 SQLite
- **Remember password**（默认勾选，密码字段非空时启用）—— 存 keychain

底部按钮文本随状态动态（`mode="create"`）：
- Save this host **勾选** + 密码非空 → `Save & Connect`（存 SQLite + keychain + 立即连接）
- Save this host **勾选** + 密码为空 → `Save & Connect`（存 SQLite，跳过 keychain，连接时会走密码 prompt 分支）
- Save this host **未勾选** → `Connect`（quick connect，不入库，同 v0.1 行为）

编辑模式（`mode="edit"`）：按钮变 `Save`，"Save this host" 复选框隐藏（既然是编辑，就一定保存），"Remember password" 密码字段留空 = 保持 keychain 里现有密码不变；密码字段有值 = 覆盖 keychain。

Dialog 复用一个 `<HostForm />` 组件，`mode` prop 决定按钮/标题/提交行为。

### 4.4 TabBar

- **＋ 按钮固定在 tabs 最右侧**，点击 = 打开 ConnectDialog
- 单 tab 也保留完整 tab 条（不再有"少一个 tab 就藏起来"的边界情况）
- 溢出：横向滚动（`overflow-x: auto; scrollbar-width: thin`）
- 键盘快捷键（新增全局 handler `useTabHotkeys` hook）：
  - `Ctrl/Cmd + T` → 打开 ConnectDialog
  - `Ctrl/Cmd + W` → 关闭当前 tab
  - `Ctrl/Cmd + Tab` / `Ctrl/Cmd + Shift + Tab` → 切下一个 / 上一个 tab
- 多个 tab 到同一 host 允许（每 tab 都是独立 UUID session），不做去重

### 4.5 空状态（无 tab 时的主区）

方案 C：
- 上：36×36 紫色圆角方块 outlined，中间 `>_` glyph（Lucide `ChevronRight` + `Minus` 组合或自绘 SVG，`stroke-width: 2`）
- 挨着：**"shellx"** wordmark，JetBrains Mono 700，28px
- 下：tagline "A tiny, pretty terminal client."（12px, `--text-2`）
- 下：主 CTA `＋ New connection` 紫按钮（10px 边距，`box-shadow: 0 4px 14px rgba(124,92,255,0.35)`）
- 下：小字 "or press ⌘K to open a saved host"（11px，`--text-3`，带 `<kbd>` 样式）

### 4.6 应用图标

同样 `>_` glyph 生成完整 icon set：
- Windows `.ico`（16 / 32 / 48 / 256）
- macOS `.icns`（16 / 32 / 128 / 256 / 512 @1× 和 @2×）
- Linux `.png`（128×128, 512×512）

流程：手绘一个 512×512 SVG 主稿 → `tauri icon` CLI 一键生成全套 → 替换 `src-tauri/icons/` 里的 placeholder。**SVG 里的紫色使用 `#7c5cff` 而非 CSS 变量**（导出为像素图后变量丢失）。

## 6. 极简 ⌘K 命令面板（f 项）

**触发**：全局 `Ctrl/Cmd + K`（`useHotkeys` 或原生 `keydown` listener）。

**行为**：
- 弹出居中面板，320 宽 × 待定高（内容驱动，最大 320px）
- 顶部单个 input，autofocus，placeholder `"Type to search hosts..."`
- 下方渲染 saved hosts 列表，输入过滤（`label` / `host` / `username` 任一 substring 匹配，case-insensitive）
- 键盘：↑↓ 选择，Enter 连接（等价于点击 drawer 中该 host）
- Esc / 点击外部背景关闭

**范围内**：仅 saved hosts 搜索 + 连接。**范围外**（推到 v0.5 完整命令面板）：quick actions、settings toggles、tab 切换、剪贴板管理、AI 补全等。

组件位置：`src/components/CommandPalette.tsx`，挂在 App 根下（不进 AppShell 里，避免布局互相影响）。数据来源：`useHostsStore()` 的 hosts 列表。

**焦点/键盘拦截**：window-level 的 `keydown` capture-phase listener 拦截 `Ctrl/Cmd+K`——**无论当前焦点在终端还是别处，全局命中**，与 VS Code / IntelliJ 惯例一致。终端里的 `Ctrl+K`（kill-line）会被抢走；用户按 `Ctrl+Shift+K` 或右键菜单里的 shell 快捷键补偿（后续 v0.5 允许自定义快捷键）。

## 7. v0.1 遗留：driver_loop natural-exit 回归测试（i 项）

Final review 的 park 项。当前 `session_closes_when_driver_exits` 测试是通过 `mgr.close()` 触发的，走 `close()` 里已有的 map 清理，没覆盖 driver_loop 自然退出路径（remote EOF / I/O error / sender-dropped）导致的清理。

**修法**：新增测试 `driver_loop_cleans_up_on_remote_eof`。用 `start_echo_ssh_server` 的返回值（`JoinHandle`）把 server 主动关掉制造 remote EOF；对应 client 侧的 `mgr.write` 会成功送出，但 `mgr.subscribe(id).recv().await` 应该收到 `None`（chan 被 driver_loop 关闭时释放）+ `mgr.list().await.is_empty()`。

Test 位置：`src-tauri/src/session/manager.rs` `#[cfg(test)] mod tests` 内。

## 10. 数据流与 IPC

新增 Tauri commands（Rust ↔ TS 双端）：

- `list_hosts() -> Vec<HostInfo>` — 无参
- `save_host(args: { label, host, port, username, notes?, password?: string })` — 若 password 非空则同时写 keychain
- `update_host(args: { id, label?, host?, port?, username?, notes?, password?: string \| null })` — 更新字段；`password: null` = 删除 keychain 里那条；`password: undefined` = 保持不变
- `delete_host(args: { id })` — 从 SQLite 删除 + keychain 删除同 UUID 密码
- `get_host_password(args: { id }) -> Option<String>` — 从 keychain 读，用于自动连接时组装 `AuthConfig`

`HostInfo` TypeScript 类型（与 Rust `Serialize` 对齐）：

```ts
export interface HostInfo {
  id: string;
  label: string;
  host: string;
  port: number;
  username: string;
  notes: string | null;
  created_at: number;
  last_connected_at: number | null;
  sort_order: number;
}
```

`SessionInfo`（`sessions.ts`）新增字段 `host_id: string | null`（quick-connect 时为 null，saved-host 触发时携带 host UUID）——用于 §4.2 bullet 状态判定。

## 13. Migration & 兼容

## 14. 里程碑与验收

**v0.2.0 验收标准**：
1. 首次启动看到新品牌空状态（icon + wordmark + CTA），点 CTA 弹 ConnectDialog
2. 填 host 信息 → 勾选 Save + Remember → Connect 成功 → 断开重开 app → drawer 里能看到该 host → 单击直连（无需再输密码）
3. 可以同时开 3 个 tab（三个不同 host / 或同一 host 三次），Ctrl+W 关闭当前，Ctrl+Tab 切换
4. `Ctrl+K` 弹出面板，输入 `prod` 过滤到 `prod-1`，回车打开新 tab
5. Drawer bullet 在 host 连接时点亮，全部 tab 关闭后熄灭
6. Linux 无 keychain 环境下，"Remember password" 灰置，"Save this host" 仍可用
7. `cargo test --lib` 至少 10 个测试通过（v0.1 有 5，v0.2 至少 +5：hosts CRUD 3-4 个、keychain 1-2 个、driver_loop natural-exit 1）；`pnpm test -- --run` 至少 10 个测试通过（v0.1 有 4，v0.2 至少 +6：hosts store 2、HostRow 1、HostForm 2、CommandPalette 1）
8. `pnpm tauri:build` 产 installer，Windows MSI 尺寸 < 15 MB

## 15. 待决事项（Open Questions）

1. **⌘K 面板中键盘导航支持**：确认只做 ↑↓ + Enter + Esc，不做 Tab / Shift+Tab / 数字键 1-9 直选？(倾向：只做 ↑↓/Enter/Esc)
2. **"Save this host" 未勾选但连接成功**：要不要在断开后弹个 toast "Save this host?"？（倾向：不做，避免打扰）
3. **同 host 打开多个 tab 时 label**：默认 tab title 是 host label；三个都开 label 会重复。要不要自动加 `(2)`、`(3)` 后缀？（倾向：不做，v0.2 就重复也无妨；未来 v0.5 可加）
4. **`Ctrl+K` 与终端里 `Ctrl+K` 的冲突**：终端里 Ctrl+K 是 kill-line（zsh/bash 常用）。要不要考虑改用 `Ctrl+P` 或 `Ctrl+Shift+K`？（倾向：`Ctrl+K` 是 palette 标准，冲突可接受；用户觉得烦再改）
