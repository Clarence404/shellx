# shellx v0.29.2

The Serial view grows up. Serial terminals now live inside the Serial view itself instead of jumping to the Hosts workspace, refresh shows what it's doing, and a reconnect bug is fixed — reopening a port you just disconnected now works.

- **Serial terminals stay in the Serial view.** Open sessions list at the top of the sidebar; the main pane embeds the selected session's terminal behind a slim header with disconnect / reconnect / close. The Serial rail entry stays highlighted throughout.
- **Reconnect fixed.** Disconnecting a port and connecting to it again no longer fails with "access denied" — the port is released promptly on close.
- **Visible refresh.** The refresh button spins while scanning and the header shows the port count and last-scan time, so a rescan is obvious even when the list is unchanged. Every scan is also logged (Settings → Logs).
- **Finds more virtual ports.** Windows port discovery now also consults the DOS device namespace, catching virtual ports some drivers register in non-standard ways.
