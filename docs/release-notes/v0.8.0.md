v0.8.0 adds public-key SSH authentication and TOFU host-key verification. Connect with Ed25519, RSA, or ECDSA keys; ShellX discovers keys in `~/.ssh/` automatically, stores passphrases in the OS keychain, and prompts only when needed. On first connect to a new server, you see the fingerprint and decide whether to trust it — accepted hosts are appended to `known_hosts`.

- **Public-key auth** — select a key in the host form; passphrase is saved to the OS keychain and reused on reconnect. Up to 3 retries before an auth-failed dialog offers alternatives.
- **TOFU host-key verification** — unknown server fingerprints show an accept/reject dialog; a mismatched fingerprint (possible MITM) shows a prominent warning with the stored vs. presented key.
- **Trusted Servers panel** — Settings → Trusted Servers lists every accepted host with its algorithm and fingerprint; one-click copy.
- **Existing hosts migrate automatically** — no action needed; pre-v0.8 saved hosts default to password auth.
