# v0.23.0 — The FTP view

A new rail view for moving files over SFTP, FTP and FTPS — the WinSCP shape: your connections on the left, local and remote panes side by side, one transfer queue at the bottom. Built for old machines too: GBK filenames, passive/active mode, and plain FTP that says out loud it is plain.

- **FTP view** — save connections for SFTP, FTP or FTPS, and the form reshapes per protocol: key authentication for SFTP, explicit/implicit TLS for FTPS, passive mode and filename encoding (auto / UTF-8 / GBK) for both FTP flavours. The pane's tags always show what the connection is actually doing: plaintext or encrypted, which charset, which transfer mode. Saved SSH hosts import as SFTP connections with one click, stored passwords and key passphrases included.
- **Transfers and drag, same as Files** — drag rows between the panes, drop OS files onto the remote side, folders walk their whole tree as one queue group. Everything lands in the same transfer strip with the same pause, resume and cancel.
- **Drag out to the desktop** — in the FTP view *and* the Files view: drag a row past the window edge and drop it in Explorer or on the desktop. Remote files download through the queue first, and a download that fails never leaves the window.
- **The Files tab loads again** — the per-tab Files activity had loaded nothing since v0.21.1; it lists the directory the moment the tab opens now. Browsing operations also carry a 30-second deadline, so a dead connection reports itself instead of showing "Loading…" forever.
