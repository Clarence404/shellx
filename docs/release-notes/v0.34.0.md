# v0.34.0

Update notices now actually show what's new. shellx no longer just says "an update is available" — it tells you what changed, formatted properly, and lets you know as soon as it finds one.

- **Proactive "what's new" card.** When the silent startup check finds a new version, a small card shows its release notes right away — dismiss it or download and restart. It won't nag again for a version you've already seen.
- **Properly formatted release notes.** Settings → About no longer dumps the raw markdown of what's new as one wall of text — headings, bullet points, and bold text now render as they're meant to.
