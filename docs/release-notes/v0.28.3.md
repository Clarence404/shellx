# shellx v0.28.3

The sidebar drawers get a visual size-up. Titles read as real titles, the collapse and import controls are bigger and clearer, and the bottom buttons line up at one height — across the Hosts, FTP, and Settings drawers.

- **Drawer titles.** "Hosts", "FTP", and "Settings" now use a proper title size instead of tiny small-caps.
- **Clearer icons.** Collapse is a bold « chevron with a hover pad; both import buttons use the standard import glyph (arrow into tray).
- **Even footer.** "New connection" and the import button beside it share one height, so the corner no longer looks like a big button with a small stub.
