# v0.32.0

The terminal's scrollback search (Ctrl+Shift+F) grows up: it now tells you how many matches there are and which one you're on, highlights every hit at once, and adds case-sensitive, whole-word, and regular-expression toggles.

- **Match counter** — the search bar shows `current / total`, and turns red with "no results" when nothing matches.
- **Highlight all matches** — every match is marked in amber and the active one in orange, so you can see the distribution across the buffer at a glance.
- **Case / whole-word / regex toggles** — three buttons next to the field; flipping one re-runs the search in place, count and highlights included.
