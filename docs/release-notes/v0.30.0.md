# shellx v0.30.0

The session monitor is rebuilt as a real dashboard. The whole machine reads at a glance, Docker and systemd get first-class views, and the window's minimum size now matches its startup size.

- **At-a-glance dashboard.** An always-visible KPI strip — CPU, memory, swap, network, disk I/O — each with a mini trend and a health chip; click a tile to jump to its detail. Performance is a responsive grid (CPU with a per-core heatmap, memory with used/cache/swap, network and disk I/O charts) that reflows and rescales with the pane; hover any chart for the value at that moment.
- **A real look back.** A load-average band (1/5/15-minute — up to 15 minutes before you opened the panel) plus since-boot totals for network, disk and average CPU, all free from `/proc`.
- **Docker containers.** Where docker is present, a Containers tab shows per-container CPU, memory, network and block I/O with health badges. It runs on its own loop so it never slows the main metrics, and loads on first open.
- **systemd alerts.** When `systemctl --failed` isn't empty, a red Alerts tab lists each failed unit with its result, exit status and time, plus one-click-copy journalctl / status / restart commands (shellx never runs sudo for you).
- **Cleaner chrome.** The view switcher sits at the host strip's right, matching the terminal view; static system specs fold into an ⓘ popover; process rows gained sort, filter and copy-PID; filesystem rows are coloured by fullness.
- **Window minimum size** now equals the startup size (1000×700), and a blank host name saves as the full `user@host` instead of just its first character.
