## v0.16.1 — Wordmark casing and terminal green

Two small follow-ups to v0.16.0:

- **Wordmark now reads "ShellX"** on the home screen (was "shellx"). The
  box tint around the mark also follows the theme accent instead of the
  old purple that was left over from before the redesign.
- **Terminal green re-tuned** so `ls` output for other-writable
  directories (ANSI 42 background + ANSI 34 blue foreground) is readable
  again on both themes. Dark theme uses a dark forest as the ow background
  and a light green for bold-green text; light theme flips this — a light
  mint as background, a deep green for bold-green text.
