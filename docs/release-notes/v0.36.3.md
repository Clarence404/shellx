A tunnel stuck reconnecting to an unreachable host can be stopped again, and the retry loop says how far it will go.

- **Stop works while reconnecting.** The row offers Stop whenever the tunnel is forwarding, dialling or waiting on a retry; pressing it cancels the retry and leaves the rule stopped.
- **The retry limit is visible.** The countdown now reads "Attempt 7/10 failed", so it is clear the loop ends by itself. Set the limit in Settings → Advanced.
- **Retry now.** Skip the backoff and dial immediately instead of waiting out the countdown.
