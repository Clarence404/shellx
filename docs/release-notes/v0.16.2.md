## v0.16.2 — Titlebar search + theme toggle

Two small conveniences moved into the top-right of the titlebar, next
to the window controls.

- **Search pill** — one click opens the command palette, with the
  `Ctrl+K` / `⌘K` shortcut printed inline so it's discoverable.
- **Theme toggle** — a sun / moon icon that flips between light and
  dark without opening Settings. The icon shows the destination, not
  the current state.
