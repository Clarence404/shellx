## 亮点

- **配置目录挪到 `~/.shellx/`** —— hosts.db 和 settings.json 现在放在用户主目录下，一眼能找到。从旧 `%APPDATA%\shellx\config\` 自动迁移过来。可用 `SHELLX_CONFIG_DIR` 环境变量自定义。
- **OS 拖拽上传** —— 从 Explorer / Finder 拖文件到 RemotePane，直接 SFTP 上传到当前远程目录。
- **Terminal 字体实时预览** —— Appearance 面板里带样本，不用切回 Terminal tab 对比字体/字号/光标组合。
- **丰富的文件右键菜单** —— 空白处右键出目录操作（New folder / Upload / Refresh），文件行右键新增 `This folder` 分组。
- **Files 工具栏图标化** —— 去掉文字标签，点击区加大，图标跟随系统字体大小滑块。
- **重命名品牌** —— identifier 改成 `io.github.clarence404.shellx`、Publisher 改成 `Clarence404`（原来是 `com.accuenergy.shellx` / `accuenergy`）。

> **从 v0.5.5 升级**：因为应用 identifier 变了，Windows / macOS 会把这一版当成完全不同的应用。装 v0.5.6 之前先在"设置 → 应用"里卸载 v0.5.5（显示为 `shellx (accuenergy)`），否则两个版本会并存。

## 配置目录

- 优先级：`SHELLX_CONFIG_DIR` 环境变量 → `~/.shellx/`（新默认）→ 旧的 ProjectDirs（Windows 上是 `%APPDATA%\shellx\config\`）作为最后 fallback。
- **一次性自动迁移**：升级后首次启动时，如果新位置是空的，`hosts.db` 和 `settings.json` 会从旧路径迁移过去（rename 优先，跨盘符 fallback 到 copy+remove）。后续启动看到新位置有文件就跳过。
- **Settings → About** 现在显示解析出来的 config dir + 各个文件的完整路径 + 如何覆盖的说明。

## OS 拖拽上传

- **从 OS Explorer / Finder 拖文件到 RemotePane** → 每个文件通过 SFTP 上传到当前 `rightPath`。
- 拖拽过程中面板加**紫色虚线外框**，明确告诉你会落到哪里。
- 用 Tauri 原生 `onDragDropEvent`（浏览器 `drop` 事件出于安全拿不到 OS 路径）。物理像素坐标通过 `devicePixelRatio` 换算成 CSS 像素做命中检测。
- 断线态自动禁用 —— 不会对失效 SFTP 句柄发操作。

## Terminal 字体预览

- **Appearance → Terminal → Preview** —— 紧凑三行样本（`root@host:~$ echo hi | grep hi` → `hi` → 光标闪烁位置），用当前选中的字体族 + 字号 + 光标样式实时渲染。
- 光标形状实时反应设置：**block** = 实心矩形、**underline** = 底部短横、**bar** = 细竖线。
- 颜色跟真实 TerminalView 主题保持一致（鼠尾草绿 prompt、青色路径、紫色光标），所见即所得。

## 工具栏和右键菜单

**Toolbar 图标化** —— FileBrowserView / LocalPane / RemotePane 顶部的 `New folder` / `Upload` 不再显示文字，只保留图标 + hover tooltip。padding 加宽，点击区舒适。图标 size = `Math.max(14, systemFontSize + 2)`，跟 System font size 滑块同步缩放。

**空白右键**（Files 面板列表下方无文件的空白区域）弹出：
- New folder
- Upload here
- ────────
- Refresh

**文件行右键**现在分两组：

```
THIS FILE
  Download
  Rename
  Delete
  ────────────
THIS FOLDER
  New folder
  Upload here
  Refresh
```

**HostContextMenu 扩展** —— 共享的右键菜单组件现在支持 `separator` 分隔线、`section` 分组标题、每项可带 `icon`；HOSTS 抽屉里原有的 Connect/Edit/Duplicate/Delete 保持不变。

## PathBreadcrumb 溢出处理

- 长路径（如 `/acucloud/influxdb3_plugins/.venv/include/python3.13`）不再把 toolbar 挤到窗口外。面包屑在 `flex: 1, minWidth: 0` 的滚动容器内；工具栏保持 `flexShrink: 0`。
- 路径变化时自动滚到末尾，最深的段总在视野内；可以滚轮/触控板横向翻回父级目录。
- 原生滚动条隐藏（新的通用 `.shellx-hide-scrollbar` 工具类）。

## Hosts 抽屉

- **Disconnect** —— host 行右键菜单现在多了一项 `Disconnect`，位置在 `Connect` 和已保存 host 操作（Edit / Duplicate / Delete）之间。只有当这个 host 有活跃会话时才显示；点击关闭所有 host_id 匹配的会话并重置 Files 面板（跟删除 host 的级联清理相同，只是不删这个 host 行）。

## Terminal

- **两阶段初始 fit** —— 挂载时同步跑一次 `fit.fit()`，下一个动画帧再跑一次。避免 shell 首个提示符字节到达时容器 layout 还没提交完，导致顶部残留截断行（比如 `root@ubunt`）的问题。
