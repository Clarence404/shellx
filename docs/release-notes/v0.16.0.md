## v0.16.0 — Light-first redesign, new logo, faster monitor

Fresh cool-blue theme, a new desktop icon, and a couple of quality-of-life
fixes across Terminal, Files, the Monitor tab, and the + menu. Existing
users keep whatever theme they had; new installs open in Light by default.

- **Themes** — new palettes, both refreshed to a cool blue (`#4C7CFF` on
  Light, `#7C9BFF` on Dark). Light is now the default and appears first
  in the picker. Existing Dark-theme users are untouched.
- **Terminal follows the theme** — xterm palette, cursor, selection, and
  the padding gutter all swap when you toggle the theme. Terminal
  background is now nudged slightly off the card colour on both themes
  so it reads as its own surface. Bottom padding raised so the last
  prompt row has room to breathe.
- **New app icon** — rounded navy square with a `>_` prompt in the new
  accent blue, regenerated across Windows / macOS / Linux / iOS / Android.
- **Quick-connect menu scrolls** — the + button's Quick Connect list
  used to cap at 6 hosts; it now shows all saved hosts with an internal
  scroll (`New local terminal` and `New SSH connection…` stay pinned).
- **Faster Monitor first paint** — the platform check + static system
  info (OS / CPU / virt / hostname) now fetch in a single SSH exec at
  session start. Per-tick poll drops from 12 subprocesses to 6, and the
  "Collecting data…" screen typically clears in well under a second on
  WAN links.
- **Window sizing** — default window bumped 800×600 → 1000×700, with a
  minWidth 820 / minHeight 600 so the rail + drawer + main pane keep
  usable proportions on resize.
