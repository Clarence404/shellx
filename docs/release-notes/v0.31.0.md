# v0.31.0

Two big additions for SSH work: dropped terminals now reconnect themselves, and you can edit remote files straight in your own editor with saves flowing back automatically.

- **Auto-reconnect for dropped SSH sessions.** When a saved-host terminal drops, shellx re-dials it under the same tab — your scrollback and layout survive — retrying with backoff. A manual **Reconnect** button appears if it gives up, and the retry interval and attempt limit are configurable in Advanced settings.
- **Edit remote files in a local editor.** Open any remote file (right-click → *Open in external editor*, or double-click when set to Edit mode) and shellx downloads it to a temp copy, opens it, and re-uploads on every save. A "watching" panel shows each file's last-saved time or upload error.
- **Configurable editor & double-click.** Point shellx at any external editor in Appearance settings, or leave it on your system default. Choose whether a double-click on a remote file downloads it or opens it for editing.
- **Watches clean up on their own.** A remote-edit watch stops when its tab closes or the connection is gone for good; a session that auto-reconnects keeps its watches and resumes uploading once it's back.
