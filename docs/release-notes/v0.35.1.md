The update dialog now shows what changed in the new version, and lets you skip a version you don't want.

- **Release notes in the update dialog.** When a new version is found, a dialog lists what's new before you download.
- **Skip this version.** Dismiss a release for good; the next newer one prompts again.
- **Titlebar Update button.** Reopen the dialog any time after closing it; it shows download progress while updating.
- **Notes ship with the update manifest.** Releases now publish their notes where the updater reads them.
