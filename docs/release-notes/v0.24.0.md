# shellx v0.24.0

The transfer strip was rebuilt around one idea: one drag, one row. A folder of twenty thousand files renders exactly like a folder of twenty — a single line with its own progress, speed and ETA — and pause, cancel and retry act on the whole gesture at once. Applies to the host Files tab, the Files view and the FTP view alike.

- **One row per gesture.** A single transfer is just the bottom bar — nothing to expand. Two or more expand into one flat row each: name, progress, speed, remaining time, pause / cancel. What file is currently moving inside a folder is never listed.
- **Multi-select counts as one gesture.** Dropping or picking many loose files at once makes one row (named after the first file), with one cancel and shared progress — same as a folder.
- **Failures stay one row too.** A failed gesture turns red in place with the failure count and the most common error, and retries or dismisses as a whole. No per-file failure list.
- **Group operations are instant at any size.** Pause, resume, cancel, retry and dismiss for a gesture are each a single backend call, so they hold even mid-queue with tens of thousands of files.
- **Steadier numbers.** Per-row speed and ETA, and finished drags no longer inflate the next drag's totals. FTP now sits after Tunnels in the rail, and the strip's resize handle is easier to grab.
