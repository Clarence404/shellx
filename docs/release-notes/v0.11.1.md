# shellx v0.11.1

A small polish release on top of v0.11.0: tunnel rules drag smoothly in both directions, and a couple of labels got tightened up.

- **Tunnel drag-reorder** — dragging a rule down and then back up works reliably; previously the row you had just swapped with couldn't be targeted again.
- **Known hosts** — the Settings section formerly called "Trusted servers" is now "Known hosts" (中文：受信主机), matching the `~/.ssh/known_hosts` file it displays.
- **`+` menu** — the quick-connect popover is now the same width as the HOSTS sidebar, so long host names truncate consistently.
