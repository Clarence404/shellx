# shellx v0.27.0

The terminal gets proper clipboard manners: Ctrl+Shift+C / Ctrl+Shift+V, a right-click menu, and a look-before-it-runs check on big pastes. The host and FTP forms now share one credential flow — same key picker, same Forget checkboxes — and closing a tab no longer whites out the one left behind.

- **Terminal clipboard.** Ctrl+Shift+C copies the selection, Ctrl+Shift+V pastes — natively, with no browser permission prompt, and pasted text looks like typing instead of a reverse-video block. Right-click offers Copy / Paste / Select all. A paste carrying line breaks (which execute on arrival) or a very long line shows a preview first.
- **One credential flow.** Both connection forms pick auth from a dropdown, share the ~/.ssh key picker (discovered keys as one-click chips, PuTTY keys flagged), offer Forget-stored-password / passphrase on edit, and say the same words in the same places.
- **Pane fix.** Open a second tab, close it, and the first tab's terminal now comes back intact — its pane used to show blank white.
- **Small polish.** The new shortcuts appear in Settings → Shortcuts, and when an update is waiting the red dot on the gear continues to the About row so the trail leads to the install button.
