## Highlights

- **Pane-to-pane drag works** — HTML5 drag turned out to be unreliable inside WebView2 + Tauri's `dragDropEnabled: true`; the entire mechanism was rewritten to use pointer events + `document.elementFromPoint` hit-testing. Drag ghost follows the cursor, target pane lights up with a purple dashed outline.
- **⇄ TransferArrow removed** — no longer needed; drag is the primary transfer affordance.
- **OS drop into LocalPane** — dragging files from Explorer/Finder into the local pane now copies them (new `local_copy_into` Rust IPC, preserves basename, recurses into directories).
- **Send to remote →** — LocalPane file rows gain a `Send to remote` context-menu entry that fires SFTP upload without needing a drag.
- **New folder inline input** — no more browser-native `prompt()` dialog in LocalPane / RemotePane; matches the FileBrowserView pattern.
- **Same-host duplicate-tab prevention** — clicking a saved host that already has an active session focuses its existing tab instead of opening a duplicate.

## Fixes

- **Terminal `root@ubunt` stale row** — TerminalView now buffers incoming shell bytes until the container's ResizeObserver reports a real size, then flushes. Prevents the shell's first prompt from writing at 0-cols when the tab body mounts hidden (Files view / Settings view / no active tab).
- **FileBrowserView "closed" after reconnect** — `useFilesStore.loadDir` soft-retries once on a `"closed"` error before surfacing it, absorbing the transient SFTP subchannel race on the freshly reconnected session.
- **Transfer completion auto-refresh** — `onTransferDone` now reloads both RailFiles panes so the new file appears without a manual refresh.
- **Files pane toolbar → icon-only** — labels dropped, hitboxes widened, icons follow the System font-size slider.
- **PathBreadcrumb overflow** — long paths scroll horizontally inside the breadcrumb bar instead of pushing toolbar buttons off screen. Wheel scrolls horizontally.

## Context menus

Empty-area right-click on any Files pane:
- New folder
- Upload here _(RemotePane only)_
- ────────
- Refresh

File-row right-click (new sectioned layout with icons):

```
THIS FILE
  Download           (RemotePane, files only)
  Send to remote →   (LocalPane, files only, remote connected)
  Rename
  Delete             (danger)
  ────────────
THIS FOLDER
  New folder
  Upload here        (RemotePane only)
  Refresh
```

Directories don't get Download / Send-to-remote (single-file IPC only — recursive is v0.6+ backlog). Hosts drawer right-click gains a **Disconnect** item when the host has a live session; closes every matching session and resets any Files pane pointing at it.

## Transfer queue

The bottom-of-pane transfer strip only appears while a transfer is in progress. Done / cancelled / failed entries stay in the store as history but stop taking vertical space — the single `io: Failure` line that used to linger indefinitely no longer sits there.

## Docs

- `CLAUDE.md` **Ship gate** now mandates auto-launching Tauri after every batch of substantive changes (no more "please launch" pings).
- README v0.6+ backlog gained two more items: directory drag between panes, context-menu clipping near pane edges.

## Under the hood

- New `local_copy_into` IPC + Rust unit-tested recursive copy.
- New Zustand action `setCurrentDrag` on `useRailFiles`; carries `{ pane, name, x, y, hoverTarget }` so the drag ghost + target-pane highlight both flow off a single source of truth.
- `HostContextMenu` supports `separator`, `section` subheader, and per-item icons (backward-compatible with existing HOSTS drawer usage).
- Two-phase Terminal fit (immediate + rAF) plus buffered writes = zero visible stale rows on hidden-mount.
