## Highlights

- **Config moved to `~/.shellx/`** — hosts.db + settings.json now live in your home directory, easy to find. Auto-migrated from the legacy `%APPDATA%\shellx\config\`. Overridable via `SHELLX_CONFIG_DIR`.
- **OS drag-drop upload** — drag files from Explorer / Finder onto RemotePane and they'll SFTP-upload to the current remote directory.
- **Terminal font live preview** in Appearance panel — no more switching tabs to compare font/size/cursor combos.
- **Rich file context menus** — empty-area right-click for folder actions (New folder / Upload / Refresh), file-row right-click extended with a `This folder` section.
- **Icon-only toolbar** in Files panes — labels dropped, hitboxes widened, icons follow the System font size slider.
- **Rebrand** — identifier `io.github.clarence404.shellx`, Publisher `Clarence404` (was `com.accuenergy.shellx` / `accuenergy`).

> **Upgrading from v0.5.5**: because the app identifier changed, Windows / macOS treat this as a different application. Uninstall the v0.5.5 build (`Add or Remove Programs` → `shellx (accuenergy)`) before installing v0.5.6, otherwise both versions will live side-by-side.

## Config location

- Priority: `SHELLX_CONFIG_DIR` env → `~/.shellx/` (new default) → legacy ProjectDirs (`%APPDATA%\shellx\config\` on Windows) as last-resort fallback.
- **One-time auto-migration**: on first startup after upgrade, `hosts.db` and `settings.json` are moved (rename → copy+remove fallback) from the legacy path if the new path is empty. Subsequent starts see the new path populated and skip migration.
- **Settings → About** now displays the resolved config dir + individual file paths + instructions for overriding.

## OS drag-drop upload

- **Drag files from OS Explorer / Finder onto RemotePane** → each file uploads to the current `rightPath` via SFTP.
- While files are dragged over, the pane grows a **purple dashed outline** so the drop target is unambiguous.
- Uses Tauri's native `onDragDropEvent` (the browser-level `drop` handler doesn't get OS paths for security). Physical-pixel positions are converted to CSS pixels via `devicePixelRatio` for accurate hit-testing.
- Disabled when the current session is closed — no attempts against dead SFTP handles.

## Terminal font preview

- **Appearance → Terminal → Preview** — a compact three-line sample (`root@host:~$ echo hi | grep hi` → `hi` → blinking cursor) rendered with the currently-selected font family + size + cursor style.
- Cursor shape reflects the setting live: **block** = filled rectangle, **underline** = short bar at baseline, **bar** = thin vertical.
- Colours match the real TerminalView theme (sage-green prompt, cyan path, purple cursor), so what you see here is what you'll get in the actual terminal tab.

## Toolbar & context menus

**Icon-only toolbar** — FileBrowserView / LocalPane / RemotePane toolbar buttons no longer show `New folder` / `Upload` text labels; only the icon + hover tooltip. Padding widened, hitbox comfortable. Icon size = `Math.max(14, systemFontSize + 2)` so pulling the System font-size slider grows them in step.

**Empty-area right-click** (in any Files pane background between/below rows) opens a menu with:
- New folder
- Upload here
- ────────
- Refresh

**File row right-click** now shows a two-section menu:

```
THIS FILE
  Download
  Rename
  Delete
  ────────────
THIS FOLDER
  New folder
  Upload here
  Refresh
```

**HostContextMenu extended** — the shared context-menu component now supports `separator`, `section` subheader, and per-item `icon`, all backward-compatible with the existing HOSTS drawer usage.

## PathBreadcrumb overflow

- Long paths (e.g. `/acucloud/influxdb3_plugins/.venv/include/python3.13`) no longer push toolbar buttons off the right side. The breadcrumb sits in a `flex: 1, minWidth: 0` scroll container; toolbar stays fixed at `flexShrink: 0`.
- Auto-scrolls to the end on path change so the deepest segment is always visible; users can wheel-scroll (or trackpad-swipe) horizontally to see parents.
- Native scrollbar hidden via the new generic `.shellx-hide-scrollbar` utility class.

## Hosts drawer

- **Disconnect** — the host-row right-click menu now surfaces a `Disconnect` action between `Connect` and the saved-host actions (Edit / Duplicate / Delete). Only appears when the host has at least one active session; closes every session tied to that saved host and resets any Files pane pointing at them (same cascade as delete-host, minus the actual row removal).

## Terminal

- **Two-phase initial fit** — `fit.fit()` now runs synchronously on mount AND again on the next animation frame, so the shell's first prompt bytes arrive after the browser has committed the final container layout. Fixes an occasional stale truncated line at the top of the terminal (e.g. `root@ubunt`) that appeared when React committed DOM before layout finalised.
