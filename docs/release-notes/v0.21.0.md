# v0.21.0 — Split panes

Drag a tab into the main area and it splits: two shells on one host side by side, a log tailing under a command prompt, a file browser beside a terminal. The tab context menu also grew the entries it was missing, and the monitor view is one scroll from top to bottom.

- **Split by dragging** — onto a pane's edge to split it, onto its middle to swap the two panes, or onto the outer band of the whole area for a full-width row above or below everything (or a full-height column beside it). Drag a pane by its header to move it; press Escape to call a drag off.
- **Splits stay even** — a third pane in the same direction joins the row as a third, not as half of one half. Drag a divider to change the balance, double-click it to level the row again; closing a pane hands its share to its neighbours in proportion.
- **Each pane picks its own view** — Terminal, Files, Tunnels and Monitor now switch per pane, so a file listing can sit beside a shell. Unsplit, the switcher floats over the top-right corner instead of owning a toolbar row.
- **Tab menu** — duplicate a host into a second session, rename a tab, copy `user@host`, close this tab or all the others. The current tab is also easier to pick out of the strip.
- **Monitor scrolls as one** — the host card scrolls away with the content while the sub-tabs, poll interval and view switcher stay pinned at the top.
- **Terminals size correctly maximised** — the last line is no longer clipped, and the gutter beneath it is even on all four sides.
