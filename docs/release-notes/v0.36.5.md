"Open download page" works again, and a development build no longer collides with an installed ShellX.

- **The download page opens.** The link in the update center and the GitHub link in Settings → About reach your browser; v0.36.1 granted the permission to open links but not the address, so every click was refused in silence.
- **Links that fail say so.** A refused link is recorded in Settings → Logs instead of looking like a dead button.
- **Dev builds keep their own config.** A build run from source uses `~/.shellx-dev/` and shows a DEV badge in the titlebar, so it can run beside an installed ShellX without sharing its hosts, settings, logs or tunnel ports.
