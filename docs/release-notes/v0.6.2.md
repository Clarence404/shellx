## Fixes

- **OS-drop folder upload works.** Dragging a folder from Explorer / Finder into the remote pane (either the RailFilesView remote side or the Hosts > Files view) previously did nothing — `sftp_upload` was called on the folder path, `LocalFile::open` failed with an IO error, and the fire-and-forget `void invoke(...)` on the JS side discarded the rejection. Drop handlers now probe each path's kind via a new `local_is_dir` IPC and route directories to `sftp_upload_dir` (recursive) instead.
- **Transfer strip hides the moment a transfer completes.** No more 5-second linger window on `done` / `failed` — the strip disappears the instant every in-flight item reaches a terminal state. `applyDone`'s 5-second entry-cleanup timer still runs but the strip stays invisible for that whole window.

## Build

- **Integration tests declare `required-features = ["test-fixtures"]`.** `cargo test` no longer fails with "unresolved import `::testing`" on the default feature set — the two SFTP / SSH integration tests are skipped unless the flag is passed:

  ```sh
  cargo test --features test-fixtures
  ```

  IDE tooling (IntelliJ Rust, rust-analyzer) also picks up the required feature and stops flagging the `protocol::ssh::testing` imports as broken.
