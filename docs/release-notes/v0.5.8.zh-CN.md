## 亮点

- **Files 字号独立滑块** —— 新增 `--font-files-size` CSS 变量、独立设置项和实时预览（文件夹 + `.log` + `.json` + `.rs` 四行 mock，跟真实 FileRow 布局一致）。跟 System font 完全解耦，调 Files 字号不再牵动其他 density 元素。
- **右键菜单靠边缘翻转** —— `HostContextMenu` mount 时先测尺寸，靠近视口下 / 右边缘会自动向上 / 向左翻。文件行、空白区、HOSTS 抽屉的菜单全部自动受益。
- **PaneSplitter 最小宽度保护** —— 硬夹在 200 px，任一 pane 不能被拖到 toolbar / 面包屑挤成一条不能用的窄条。
- **滑块范围统一** —— `SYSTEM_FONT_SIZE_MAX` 从 16 提到 18，System / Files 共享同一个 11-18 区间。相同数值（比如 13 px）现在两条滑块的 thumb 位置完全对齐。

## Appearance 面板重排

- 两列网格布局：110 px 固定 label 列 + 1fr 控件列，label 和控件同行，不再叠成两行。
- 章节标题升级：`text-1` + 字重 600 + `--border-hi` 下划线，Interface / System font / Files / Terminal 明显区分。
- **System font** 独立成一节（原本挤在 Interface 里），Family / Size 拆两行，跟 Terminal 章节结构对齐。
- 所有内联控件（select / slider / segmented）统一 `width: 320px`，右边缘对齐；Preview 保留宽卡片。
- 主题卡片瘦身（min-width 120 → 96、色带更窄），面板顶部不再被主题选择占满。
