# shellx v0.11.2

One targeted fix: switching a host out of tunnels-only mode now gives its live sessions a working terminal.

- **Mode switch gains a shell** — if a host was connected in Tunnels-only mode and you later switch it to Terminal only or Term + Tunnels, its open sessions get a shell immediately on save (correctly sized) — no reconnect needed. Previously the terminal tab stayed blank until you closed and reopened the connection.
