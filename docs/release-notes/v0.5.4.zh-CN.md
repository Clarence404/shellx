## 亮点

- 左侧功能列改成 icon + 文字上下排列 —— 不再误点
- 标题栏空白区（有/没有 tab 都算）现在都能拖窗口

## 功能列（Rail）

- `--rail-w` 从 32 拓宽到 64 px。每个按钮变成图标 + 文字上下堆叠（Hosts / Files /
  Protocols / Settings），舒适的 ~40 × 44 点击区域，替代原来 28 × 28 的纯图标胶囊。
- Hover 用低饱和度的 `--border` 提示；只有当前选中的视图保持 accent 高亮，避免视觉冲突。

## 标题栏

- tab 条的空白部分（tab 之间的间隙，或完全没有 tab 时的整个条）现在都是
  `data-tauri-drag-region`。抓任何空白位置都能拖窗口，三平台一致。
- Tab、`+` 按钮、`‹ › ≡` 溢出控件、min/max/close 保持原有交互 —— 拖拽区会自动让位给
  这些原生点击目标。
