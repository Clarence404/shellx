## v0.15.0 — Session Monitor

Every SSH session now has a **Monitor** tab (alongside Terminal / Files / Tunnels) that streams live CPU, memory, network, process, and disk metrics from the remote Linux host over the same connection. First snapshot lands the instant you open the tab; interval is user-adjustable from 1 s to 30 s.

- **Performance page** — CPU % with sparkline and per-core bars, memory + swap gauges, aggregated network throughput, disk I/O — each with a Healthy / Warning / Critical badge above 60 % / 85 %.
- **Process page** — top 50 processes sorted by CPU, with CPU / MEM highlights on the leaders. Column labeled `CPU%(avg)` to make clear the value is ps's lifetime average, not instantaneous.
- **Disk page** — every mount point (real disks, tmpfs, overlay, Docker layers included), used / total / avail per row, aggregate summary in the header. Panel scrolls when the list is long.
- **Host info card** — OS distro badge, kernel, CPU model, hostname, boot time, virtualization type, architecture, memory, IP, uptime — all pulled from `/etc/os-release`, `/proc/cpuinfo`, and `systemd-detect-virt`.
- **Refresh** dropdown in the sub-tab bar (1 s / 2 s / 5 s / 10 s / 30 s); the poll loop restarts with the new interval immediately.
- Non-Linux hosts show a graceful "Monitoring is not supported (Linux only)" message instead of failing silently.
- Monitor UI strings are fully translated between 中文 / English and follow the app-wide language setting.
