# v0.35.0

Your saved hosts can now be organised into groups, and the host list has a search box. Nothing changes until you make your first group — the list looks exactly as it did.

- **Host groups.** File each host under a group (prod, test, home…) from the host form, by right-clicking it, or by Ctrl-selecting several and choosing Move. Groups collapse, show how many of their hosts are online, and can be renamed or dissolved without touching the hosts inside.
- **Search the host list.** A search box above the list filters by name, address, user or group as you type, highlights the match, and opens any group that has a hit. Esc clears it; Enter connects to the first match.
- **Groups travel with your config.** Exporting and importing a config bundle keeps each host's group; bundles from earlier versions import as ungrouped.
