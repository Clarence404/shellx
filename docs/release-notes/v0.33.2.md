# v0.33.2

Two terminal input fixes: pasting a multi-line file into an editor no longer mangles its indentation, and the command-suggestion dropdown's mouse and keyboard handling both work as intended.

- **Paste no longer staircases indentation in vim/nano.** Those editors ask the terminal to mark a paste with bracketed-paste sequences specifically so they can tell it apart from fast typing and skip their own autoindent; shellx now sends that marker whenever the remote program has actually requested it, so a multi-line file (a YAML compose file, say) pastes in with its original indentation intact. A plain shell prompt that never asked for it is unaffected.
- **Command suggestions: click now works, and Enter fills in rather than running.** Hovering a suggestion no longer rebuilds the whole list out from under the pointer, which was making clicks unreliable. And selecting a suggestion with ↓ then Enter now only completes the line — it no longer submits it — matching what a mouse click already did.
