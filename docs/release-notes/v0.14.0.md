# v0.14.0 — Auto-update

ShellX now checks for new releases automatically and lets you download and apply them without leaving the app.

## What's new

- **Startup update check** — on launch, ShellX silently checks for a new release in the background. If one is available, a dot appears on the Settings rail icon. No pop-ups, no blocking.
- **About panel update UI** — open Settings → About to see the new version, release notes excerpt, and a "Download & restart" button. The download runs with a live progress bar; ShellX relaunches automatically when it finishes.
- **Manual check** — hit "Check for updates" any time to trigger an on-demand check. Results (up to date / new version / error) are shown inline.
- **Auto-check toggle** — turn off the startup check in Settings → About if you prefer manual control.
- **Signed releases** — all builds are signed with a Minisign key; the updater verifies the signature before applying any update.
