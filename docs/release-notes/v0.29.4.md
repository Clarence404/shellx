# shellx v0.29.4

A small terminal fix: pasting now jumps to the live prompt.

- **Paste scrolls to the bottom.** When you were scrolled up in the history and pasted (Ctrl+Shift+V, right-click, or the paste dialog), the view stayed put and the pasted line landed off-screen. It now snaps to the prompt like typing does, across SSH, local, and serial terminals.
