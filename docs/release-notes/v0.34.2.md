# v0.34.2

A small update-checker polish: a failed check no longer looks like something broke.

- **Calmer message when a check fails.** Settings → About used to show a raw technical error in a red box when the update check couldn't reach the server (most often because a new release is still being published). It now just says the release is in progress and to try again later, in a neutral tone — the underlying detail is still there as a tooltip if you need it.
