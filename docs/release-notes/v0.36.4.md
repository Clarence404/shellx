The titlebar's download button now opens an update center, so the result of a check stays on screen instead of flashing past as a tick.

- **Update center.** Clicking the button opens a dialog that checks from inside it and shows what it found: an available update with its notes, "shellx is up to date", or a failed check — each with a way to open the download page or look again.
- **Clearer failures.** A check that could not reach GitHub no longer reports itself as a download that did not finish.
