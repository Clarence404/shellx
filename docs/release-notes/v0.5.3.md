## Highlights

- Sans UI font family AND size are now user-controllable under Settings → Appearance
- Themes trimmed to Warm Minimal + Warm Light; stale `ocean`/`forest` values auto-migrate
- Tab bar overflow: chevrons + tab-list dropdown, wheel-scroll, and per-tab right-click Close all / Close left / Close right
- Terminal edge padding is now consistent across light and dark themes
- Closed sessions no longer appear in the RemotePane host picker

## Settings

- **System font size** (Appearance → INTERFACE) — new slider (11–16 px) that scales every sans UI element: tabs, sidebar rows, Settings labels, host list, right-click menus, Terminal | Files toggle, buttons.
- **Appearance panel** re-grouped into `INTERFACE` and `TERMINAL` sections. Font family + size sit inline on one row.
- **Themes trimmed** — dropped Ocean and Forest. Only **Warm Minimal** and **Warm Light** ship. Old `settings.json` files with `ocean`/`forest` coerce to Warm Minimal on load.
- Reset to defaults + all context menu items honour the System font size.

## Titlebar & tabs

- **Overflow chrome** — when tabs exceed the titlebar's width, a compact cluster `‹ › ≡` appears at the right end. Chevrons scroll the strip; the list icon opens a scrollable dropdown of every tab with per-row close.
- **Wheel scroll** on the tab strip; native scrollbar hidden so pills no longer clip.
- **Right-click a tab** → `Close N to the left` / `Close N to the right` / `Close all` (danger).
- Active tab auto-scrolls into view when cycled via `Ctrl+Tab`.
- 24 px drag gutter between the tab-chrome cluster and window controls (min / max / close).

## Fixes

- **Terminal edge padding** — light theme no longer shows a white gutter around the dark terminal canvas. Container background now matches the terminal's own theme background in both themes.
- **Closed sessions in Host picker** — the RemotePane dropdown no longer lists already-closed quick-connect sessions.
- **Stale `rightHost`** — when a session tab is closed, RemotePane resets to "Pick a host" instead of clinging to a dead id and rendering a phantom `/root` breadcrumb.

## Under the hood

- New `Settings.systemFontSize: u32` field; pre-v0.5.3 `settings.json` files load cleanly via serde default 13.
- `--font-ui-size` CSS custom property drives every sans chrome fontSize refactored this release.
- Rust lib: 31/31 tests pass. Vitest: 106/106 pass.
