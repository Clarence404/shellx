# v0.19.0 — logs for every subsystem

Settings → Logs now records the whole app, not just tunnels. Sessions, file operations, transfers, the monitor, saved hosts, the keychain and the updater all write into the same stream, so the panel has something to show whichever part of shellx you are chasing.

- **New `transfer` category** — one line per queued upload or download and one when it ends, at the level its outcome deserves: finished, cancelled, or failed with the error and the byte count it stopped at.
- **Session lifecycle** — connect attempt, handshake result and auth method, shell-channel failures, host-key accept and reject with the fingerprint, local terminal open and exit, and why a tunnels-only transport was dropped.
- **Files, monitor, hosts, keychain, updater** — remote renames, deletes and mkdirs at info with directory reads at debug; monitor poll failures with the count that ends the loop; host saves and deletes; every keychain write that did not land; update checks, downloads and installs. Passwords, passphrases and key material are never recorded — only the host an entry belongs to.
- **A startup line** — every run opens with the version, OS, architecture and config directory, so an exported jsonl says what produced it.
