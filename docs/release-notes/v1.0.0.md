ShellX reaches 1.0. Everything the README describes — SSH terminals, SFTP and FTP, port forwarding, serial consoles, the monitor dashboard and threshold alerts — is in and has been used daily for months. The version number is catching up with the app.

- **Screenshots in the README.** The saved-host sidebar and the Tunnels view, so the project page shows what it is before you install it.
- **A corrupt row no longer empties the host list.** A host the database can't read is skipped and logged; the rest still list. One bad row used to make the sidebar look empty with nothing to explain it.
- **Tests around the tunnel row.** Copying an address or an ssh command, stopping a tunnel mid-reconnect, and the retry countdown are covered, so the fixes from 0.36.x stay fixed.
