# v0.17.0 — global Tunnels view

Tunnels are now a top-level thing. A new Tunnels entry in the sidebar shows every saved forward from every host in one place, grouped by host — start any rule directly from here and shellx opens the SSH transport silently in the background (no terminal tab needed). Import from an `ssh -L …` command, drag rows to reorder, or move a rule to a different host without recreating it.

- **Global Tunnels view** — sidebar → Tunnels shows every rule across every saved host, grouped by host, with per-row Start / Stop / Copy / Delete. Starting a rule opens a silent SSH transport when the host isn't already connected; the terminal tab list stays untouched.
- **Inline SSH command import** — top-right *Import* button opens a parser bar: paste `ssh -L 5432:localhost:5432 user@host`, pick which saved host to attach the rules to, and bulk-add.
- **Reorder + rehome** — rows drag inside their host group to reorder, and the edit drawer's *Via SSH host* selector can now move a rule to a different host without delete + recreate.
- **Refined edit surface** — inline "Confirm delete?" pill replaces the system dialog; Copy button flashes a green check; the flow diagram's middle node shows the selected SSH host label instead of a generic "Firewall".
- **Host dialog simplification** — the New / Edit host dialog no longer has a Tunnels tab; rules live only in the global view.
