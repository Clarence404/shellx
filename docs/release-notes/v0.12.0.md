# ShellX v0.12.0

Terminal search arrives: press Ctrl+Shift+F to search your scrollback. Settings also gains a shortcuts reference page.

- **Search in terminal** — `Ctrl+Shift+F` opens a floating search bar over any terminal (SSH or local). Matches highlight as you type; `Enter` / `Shift+Enter` step forward and back; `Esc` closes and returns focus to the shell. `Ctrl+F` still passes through to the shell untouched.
- **Shortcuts page** — Settings → Shortcuts lists every keyboard binding in one place (English and Chinese). Bindings are fixed for now; customization is on the roadmap.
