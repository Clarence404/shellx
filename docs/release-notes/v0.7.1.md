Two bugs that landed with v0.7.0 fixed, plus the architecture diagram in the README swapped out for a proper SVG (in both English and Chinese) so it renders identically everywhere.

## Fixes

- **Freshly opened terminal keeps its prompt.** New tabs no longer paint blank on first render — the welcome banner and shell prompt land immediately, no Enter-to-wake needed.
- **Files pane Reconnect works.** After closing a terminal and opening a fresh one to the same host from elsewhere, the Files pane now follows the live connection automatically instead of leaving you stuck on a dead DisconnectedPanel.

## Docs

- Architecture diagram in `README.md` / `README.zh-CN.md` replaced with `docs/architecture.svg` (English) and `docs/architecture.zh-CN.svg` (Chinese) — same design, guaranteed to render on GitHub in any theme.
