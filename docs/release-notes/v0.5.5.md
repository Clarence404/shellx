## Highlights

- **RemotePane disconnected panel** — closing an SSH tab no longer leaves the Files view in a broken "closed" state; a proper card offers Reconnect / Pick different host
- **Terminal palette** — muted sage green so `ls`'s other-writable directory case (blue text on green bg) is finally readable
- **Deleting a saved host now cleans up** its live sessions and resets any Files pane pointing at them
- **New SSH connection form** — captions and checkboxes match the heading in prominence (no more washed-out labels)
- **Breadcrumb `C:` fix** — clicking the drive-letter chip actually lands on the drive root

## Files / RemotePane

- **DisconnectedPanel** replaces the broken empty listing when a session is closed or purged. Shows the host label, a plug-off icon, and either `Reconnect` (for saved hosts) or `Pick different host` (for quick-connect sessions). Reconnect kicks off `openConnection` with keychain credentials; RailFilesView's growth watcher then swaps `rightHost` to the new session id.
- **`setRightHost` full state reset** — additionally clears `rightError` and `rightLoading` on every host switch, so a stale `closed` error from the previous session no longer leaks onto the new pane.
- **sftpRealpath fallback** — when the freshly-connected SFTP subchannel transiently returns `closed` before its russh handshake settles, `setRightHost` now falls back to `/` and lets `loadRight` own the error reporting, instead of stamping the transient error on the pane.
- **`..` guard** — no longer renders during the brief empty-path window between reset and realpath resolution.
- **HostDropdown** — shows a `closed` badge next to the label when the current host's session isn't active; falls back to the saved-host label after `useSessions` purges the closed session.
- **Breadcrumb drive-letter fix** — clicking `C:` in the path bar now navigates to the drive root (`C:/`) instead of silently landing on the shellx.exe process CWD (Rust's `canonicalize("C:")` treats a bare `C:` as "cwd on drive C").

## Terminal

- **ANSI green palette** shifted to muted sage: `green: #a6e3a1 → #7c9c80`, `brightGreen: #b8ecb0 → #95b298`. The former pastel green washed blue foreground text out to near-invisibility on `ls`'s `ow` / `tw` (other-writable / sticky-writable directory) colouring.

## Titlebar & tabs

- **Tab strip empty area is now a drag surface** — grabbing an empty patch between tabs (or the whole strip with zero tabs open) drags the window. TabBar's outer container also grew a `flex: 1, minWidth: 0` so the strip fully consumes the wrapper (previously left a non-draggable gap between tabs and window controls).

## Activity rail

- **Rail labels follow the System font size** setting (`calc(var(--font-ui-size) - 2px)`), so the four labels (`Hosts` / `Files` / `Protocols` / `Settings`) scale together with tabs, sidebar rows, host list, and every other sans-chrome element.

## Hosts drawer

- **Auto-hide when empty** — with no saved hosts, the drawer disappears entirely. The main-area EmptyState already offers the `+ New connection` action, so the empty drawer is pure noise until the user's first host lands.
- **Delete cascade** — deleting a saved host now closes every live session linked to it (via `session.host_id`), removes the corresponding tabs from the Zustand store, and resets `useRailFiles.rightHost` if the Files view was pointing at any of those sessions. Prevents orphan tabs and phantom `/root` breadcrumbs.
- **Auto-collapse on connect** — `addSession` now sets `drawerCollapsed: true`, so the drawer folds away as soon as a new session becomes active and the terminal takes full width.

## HostForm (New SSH connection dialog)

- Field captions (`LABEL` / `HOST` / `PORT` / `USERNAME` / `PASSWORD`) upgraded from `var(--text-3)` at 10 px to `var(--text-1)` at 11 px with `fontWeight: 500`, matching the dialog heading's prominence.
- Checkbox row labels (`Save this host`, `Remember password`, `Forget stored password`) upgraded from `var(--text-2)` to `var(--text-1)`. Disabled-state greying (`Remember password` when no keychain / empty password) preserved via `var(--text-3)`.
