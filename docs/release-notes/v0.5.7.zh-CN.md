## 亮点

- **面板间拖拽终于能用了** —— HTML5 drag 在 WebView2 + Tauri `dragDropEnabled: true` 下不可靠，整个机制改成 pointer events + `document.elementFromPoint` 命中检测。拖动时有跟随光标的浮动 ghost，目标 pane 亮起紫色虚线外框。
- **移除中间的 ⇄ 按钮** —— 不再需要，拖拽已是主要传输方式。
- **OS 拖到 LocalPane** —— 从 Explorer / Finder 拖文件到 LocalPane 会调用新的 `local_copy_into` Rust IPC 复制到 leftPath（保留 basename、目录递归）。
- **Send to remote →** —— LocalPane 文件行右键菜单增加了这一项，直接调 SFTP 上传，不需要拖拽也能上传。
- **New folder 内联输入** —— LocalPane / RemotePane 不再弹浏览器原生 `prompt()` 对话框，改成顶部内联输入行（跟 FileBrowserView 一致）。
- **同 host 不再重复开 tab** —— 点击一个已经有活会话的 host，会切到那个 tab，而不是新开一个。

## 修复

- **Terminal `root@ubunt` 残行** —— TerminalView 现在缓冲 shell 送来的字节，等 ResizeObserver 报告真实尺寸后再 flush。避免 tab body 隐挂（Files 视图/Settings 视图下）时，shell 的第一个提示符按 0 cols 写下。
- **FileBrowserView reconnect 后显示 "closed"** —— `useFilesStore.loadDir` 对 "closed" 错误软重试一次再上报，吸收新连接 SFTP 子通道 russh 握手 race。
- **传输完成自动刷新** —— `onTransferDone` 现在自动刷新两个 RailFiles 面板，新文件立刻出现。
- **Files 面板 toolbar 图标化** —— 去文字标签，点击区加宽，图标跟随 System font size 滑块缩放。
- **PathBreadcrumb 溢出** —— 长路径在面包屑内部横向滚动，不再挤走 toolbar 按钮。鼠标滚轮触发横滚。

## 右键菜单

任意 Files 面板空白区右键：
- New folder
- Upload here _(仅 RemotePane)_
- ────────
- Refresh

文件行右键（新的分组布局 + 图标）：

```
THIS FILE
  Download           (仅 RemotePane，仅文件)
  Send to remote →   (LocalPane，仅文件，需远程已连接)
  Rename
  Delete             (danger)
  ────────────
THIS FOLDER
  New folder
  Upload here        (仅 RemotePane)
  Refresh
```

目录不显示 Download / Send-to-remote（IPC 是单文件的，递归目录传输在 v0.6+ backlog）。Hosts 抽屉的 host 行右键当有活会话时新增 **Disconnect**，关闭该 host 的所有活会话并重置 Files 面板。

## 传输队列

底部传输条现在只在有进行中的传输时显示。完成/取消/失败的记录还在 store 里但不占垂直空间 —— 之前那条永远挂着的 `io: Failure` 消失。

## 文档

- `CLAUDE.md` **Ship gate** 现在明确要求：每次改完就自动 launch Tauri，不用用户说"启动"。
- README v0.6+ backlog 加了两条：目录面板间拖拽、右键菜单靠边裁剪。

## 底层

- 新 `local_copy_into` IPC + Rust 单测（递归 copy）。
- `useRailFiles` 新增 `setCurrentDrag` action；`currentDrag` 携带 `{ pane, name, x, y, hoverTarget }`，让拖拽 ghost 和目标 pane 高亮从同一 source of truth 流出。
- `HostContextMenu` 支持 `separator`、`section` 分组标题、每项可带 icon（向后兼容 HOSTS 抽屉的用法）。
- Terminal 两阶段 fit（同步 + rAF）+ 缓冲写 = 隐挂时零残行。
