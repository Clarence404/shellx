# v0.18.1 — connecting-state border polish

Tunnel cards now show a rotating gradient border while a tunnel is opening, so a mid-connect state reads at a glance from across the list. First-time connects sweep in accent blue; recoveries from a dropped active tunnel sweep in warning orange — different animations for genuinely different situations.

- **Blue sweep for first-connect** — cards animate blue whenever the tunnel has never been active this session. Covers the moment right after clicking Play, and the retry loop when an autostarted rule can't reach a not-yet-connected host.
- **Orange sweep for reconnect** — reserved for tunnels that were actually up and are now recovering. The old behaviour lumped both cases together and mislabelled autostart failures as "reconnecting".
- **Cleaner retry hint** — the countdown no longer reads `第 #0 次失败, 下次在 1s` before any attempt has actually happened. Attempt count is only shown once at least one dial has finished.
