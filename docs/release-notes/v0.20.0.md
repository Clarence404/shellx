# v0.20.0 — Advanced settings

Settings → Advanced is live: SSH timeouts and keepalive, concurrent transfers, terminal scrollback, tunnel reconnect policy, and log detail are all yours to set. Running tunnels also survive a window reload now — the Tunnels view asks the backend what is actually forwarding instead of relying on its own memory.

- **SSH connection** — connect timeout, keepalive interval and unanswered-probe limit, applied to every new connection without a restart.
- **File transfers** — pick how many uploads and downloads run at once; the rest wait in the queue, and cancelling a queued one takes effect immediately.
- **Terminal and tunnels** — scrollback depth for new terminals, plus the first retry delay and attempt ceiling for tunnel auto-reconnect.
- **Log detail** — choose the minimum level recorded. It governs the ring buffer, the live stream and the daily jsonl file, not just what the panel shows (takes effect on restart).
- **Tunnels reattach on reload** — a running rule reads Running and its Stop button works, whatever happened to the window in between.
