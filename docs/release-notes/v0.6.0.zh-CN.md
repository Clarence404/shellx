## 亮点

- **目录传输** —— 新 Rust IPC 家族 `sftp_upload_dir` / `sftp_download_dir`：遍历源目录树，parents-first 地在目标端 mkdir，每个文件叶子起一个独立传输任务。同一目录传输的所有子任务共享一个 `group_id`，前端因此可以把它们聚合成一行显示。
- **暂停 / 继续** —— 任意进行中的传输（或整个目录组）都可以中途暂停后再继续。底层是一个共享 `pause_flag: Arc<AtomicBool>`，字节泵循环短周期轮询；新增 `transfer:state` 事件让 UI 立即翻到 paused，不用等下一个 progress tick。
- **取消真正会停** —— `write_all`（和下载侧的 `read`）现在跟 `cancel_rx` 一起包在 `tokio::select!` 里。之前只在 chunk 之间检查 cancel，一个卡死的 SFTP write 就把信号吞了；现在写卡住也立即响应取消。取消一个 paused 的任务时也会同步把 pause 关掉，避免循环僵在暂停状态收不到信号。
- **底部条聚合** —— 30 个文件的目录上传现在渲染成一行（`⬆ 📁 project/  4/30 files  12/240 MB · 5%`），整行进度填充作为背景。点前面的 `▸` 展开可以看每个子文件的行（也用同样的整行填充样式）。组头一键 pause / resume / cancel 对所有子任务批量操作。
- **递归删除目录** —— 新 `sftp_remove_dir_recursive` IPC：先遍历再 bottom-up 删。RemotePane 删目录行时自动走这个，v0.6 之前刚上传的目录会因为 SFTP `RMDIR` 只接受空目录而删失败，现在能正常删了。

## 底层

- **`SessionManager` 结构调整** —— 内部 map 从 `HashMap<Id, LiveConnection>` 改成 `HashMap<Id, Arc<Mutex<LiveConnection>>>`。原来的 "从 map 取出 → 操作 → 放回" 模式在并发场景下有 race：并发的 `sftp_open_write` 会看到 map 短暂为空然后 `Error::Closed`。10 并发目录传输把这个 bug 暴露了；per-connection mutex 修好了它，外层 map lock 只在查找 / 插入 / 移除时短暂持有。
- **`TransferInfo` schema** —— 新增可选 `groupId` 字段（wire 上用 `camelCase`；结构其他字段仍是 `snake_case` 保持和前端类型对齐）。单文件传输的 `groupId` 为 `null`。
- **`TransferState::Paused`** —— 与 `queued / active / done / cancelled / failed` 并列的新枚举变体。
- **`transfer:state` 事件** —— 状态跟 progress tick 无关地翻转时发（目前是 pause / resume）。前端由 `useTransfersStore.applyState` 消费。
- **"永远 queued" bug 修复** —— Rust 的 `mark_active` 只改内存 info，前端看不到状态跳转。`applyProgress` 现在收到第一个 bytes tick 就自动把 `queued` 提升到 `active`。

## 前端

- **`ProgressRow`** —— 新的共享行组件，背景是整行填充（active 紫色 → paused 琥珀色 → failed 红色）。组头行和单文件行都用它。
- **目录拖拽** —— LocalPane / RemotePane 的 pointer 拖拽不再拦截 `kind === "directory"`；drop 时按 kind 路由到递归 IPC。
- **目录右键下载** —— 远端目录行右键 Download，弹目录选择器（而不是文件保存框）作为下载目的地。
- **本地目录 Send to remote** —— LocalPane 目录行右键菜单加了 Send to remote，走 `sftp_upload_dir`。
- **底部条高度上限** —— 整个 TransferQueue 限制 `max-height: 36vh` 内部滚动；展开的子任务列表限制 200 px。500 个文件的目录传输不再把 pane 挤没。
- **cancel / pause / resume 按钮** —— 每行头部都有 `⏸ / ▶`（按上下文切换）和 `✕`，加大了点击热区。
