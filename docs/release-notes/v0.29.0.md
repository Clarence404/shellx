# shellx v0.29.0

The Serial rail comes alive: shellx now speaks RS-232. Browse the machine's COM ports, connect in one click or save a profile with full line settings, and work the device in the same terminal you already know — clipboard, shortcuts and split panes included.

- **Live port discovery.** The Serial view lists every COM port on the machine, with USB-serial adapters showing their chip name (CH340, FT232…); one refresh button re-scans after plugging in a cable.
- **Quick connect or saved profiles.** Connect any port instantly at 115200 8N1, or save a named profile choosing baud rate, data/stop bits, parity and flow control from dropdowns. Profiles live in the sidebar with a status dot, right-click to edit or delete.
- **A real terminal tab.** A serial session opens as a normal tab next to your SSH and local shells — copy/paste, right-click menu, and split panes all work. One session per port; closing the tab frees the port cleanly, and unplugging the adapter marks the tab closed.
