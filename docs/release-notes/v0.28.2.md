# shellx v0.28.2

Dialog polish across the app. Every modal now puts Cancel on the left and the confirming action on the right; the delete-host dialog states real consequences (or nothing) instead of boilerplate; and a host whose name is cleared while editing saves as user@host instead of blank.

- **One button order.** Cancel left, primary action right, in every dialog — delete confirmation, connection forms, imports, paste confirmation, snippets.
- **Honest delete dialog.** It counts what the delete actually cuts — "2 open sessions will close · 3 tunnel rules go with it" — and says nothing at all when nothing is affected.
- **Names never save blank.** Clearing a host's name and saving falls back to user@host, in both the host and FTP forms, matching what the placeholder promises.
- **Tidier checkboxes.** The Forget-stored-password rows lay out as label plus explanation instead of wrapping mid-word.
