v0.7.0 is a UX polish + bugfix pass. The Files pane gets manual path entry
and a Windows / macOS / Linux disk picker on the first breadcrumb segment.
The Hosts view grows two new "connecting…" states (first-connect and SFTP
reconnect) with a shared plug-pulse animation, so the empty EmptyState and
DisconnectedPanel no longer sit motionless during an in-flight handshake.
The `+` button in the tab bar opens a quick-connect menu instead of jumping
straight to the New-Connection dialog. Native `alert()` popups are replaced
with a centered in-app modal. And the long-standing multi-shell "blank
prompt on old tabs" bug — where switching to an older shell tab showed a
blank buffer until you pressed Enter — is fixed.

## Files pane

- **Editable path bar.** Single-click the empty area of the breadcrumb row (or double-click any segment) → the breadcrumb turns into a text input pre-filled with the current path, all selected. `Enter` navigates, `Esc` / blur cancels without navigation (so an accidental focus loss doesn't jump the pane). Works in both LocalPane and RemotePane.
- **Disk / volume picker on the first segment.** Clicking `C:` on Windows (or `/` on macOS / Linux) in the LocalPane breadcrumb opens a popover of available disks. New Rust IPC `local_list_disks`:
  - Windows: `GetLogicalDrives` bitmap → `A:` through `Z:` for each set bit (no per-drive volume-label probe — that would hang on disconnected network drives).
  - macOS: `/` plus non-hidden entries under `/Volumes`, deduped against the root symlink Apple leaves in there.
  - Linux: `/` plus non-hidden subdirs of `/media/<user>` (systemd auto-mount) and `/mnt` (manual mounts).

  RemotePane doesn't get the picker — SFTP has a single `/` root.

## Connecting animation

- **Shared `ConnectingPanel`.** Two plug icons drift toward each other with a three-dot pulse between them; pure CSS keyframes (no JS animation loop). Used in two places:

  - **First-connect from Hosts sidebar.** Clicking a saved host used to leave the main pane on the ShellX EmptyState until the SSH handshake finished — no visible feedback beyond a subtle rail dot. Now the whole pane shows "Connecting to `<host>`…" the moment `beginConnecting` fires and switches to the terminal once `addSession` lands.
  - **SFTP Reconnect from DisconnectedPanel.** Same panel, `Reconnecting to <host>…` label.

- Both panels include a `Cancel` button that clears the connecting flag; the underlying `openConnection` can't be aborted mid-flight, so if it succeeds anyway the session still lands as a tab (findable from the tab bar).

## `+` button quick-connect menu

- **Tab bar `+` now opens a menu**, not the New-Connection dialog directly. Three sections:
  1. **New local terminal** — reserved slot with a "Soon" badge (backend `pty` support is a separate future feature).
  2. **Quick connect** — up to 6 saved hosts, single-click to start a fresh SSH connect (defers to the existing `handleConnectSavedHost` dedup so double-firing on an already-active host is a no-op).
  3. **New SSH connection…** — opens the full ConnectDialog (the old `+` behavior).

## Terminal

- **Old shell tabs keep their prompt after opening a new one.** Previously the app rendered a single `<TerminalView sessionId={activeId} />` for the whole hosts view; switching tabs disposed the current xterm instance and mounted a fresh one for the newly-active session, discarding everything the previous shell had written to the buffer. The freshly-mounted terminal only received bytes from the mount point onward — so revisiting an older tab showed a blank terminal until you hit Enter and the shell echoed a new prompt. Now every session's `TerminalView` + `FileBrowserView` stays mounted for the lifetime of its tab and switching is a `display: block/none` flip. Each xterm keeps its own scrollback intact across tab switches.

## Dialogs

- **Centered in-app error modal.** New `ErrorDialog` component replaces the two `alert()` call sites (connect failure, SFTP delete failure). Backdrop covers the full viewport with a soft dim; the card is centered vertically + horizontally in the ShellX window. Dismiss via the OK button, backdrop click, `Escape`, or `Enter`. Fades in with a 120ms easing.

## Under the hood

- Extracted `ConnectingPanel` as a shared component from RemotePane's inline `ReconnectingPanel` — same visual language now applies to any future "connection in flight" state without duplicating the animation.
- Two new CSS keyframes in `reset.css`: `shellx-plug-left` / `shellx-plug-right` for the drifting plugs, `shellx-dot-pulse` for the three-dot pulse, `shellx-fade-in` for the ErrorDialog backdrop.
