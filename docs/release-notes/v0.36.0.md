Set CPU, memory, disk, swap and load limits in Settings → Alerts, and shellx tells you when a host crosses one — even with the monitor closed.

- **Threshold alerts.** Five rules plus a watch on units entering `systemctl --failed`. Each has its own switch and limit; alerts are off until you turn them on.
- **It finds you.** A toast, a Windows notification, a badge on the host in the sidebar, and an entry in the monitor's Alerts tab.
- **Sampling keeps going.** Connected hosts are polled every 10 seconds with the monitor panel closed, so an alert doesn't need you to be watching.
- **Quiet by design.** A rule must breach several samples in a row before it fires, then stays quiet for a cooldown, and clears only once the reading has fallen clear of its threshold.
