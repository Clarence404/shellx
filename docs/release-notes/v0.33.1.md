# v0.33.1

Fixes the terminal scrollback search (Ctrl+Shift+F) introduced in v0.32.0, which reported "no results" and drew no highlights even when the term was clearly on screen.

- **Search works again** — the highlight-all path relies on an xterm API the terminal hadn't opted into, so it threw and aborted the search before it could count or select a match. The terminal now enables it, so the match counter, highlight-all, and case / whole-word / regex toggles all work.
