# v0.22.0 — Bring your hosts with you

Getting your machines into shellx no longer means typing them in. Import them straight from `~/.ssh/config`, or carry a whole setup — hosts, tunnel rules, settings — to another computer as one JSON file. And when a list arrives all at once, it can leave all at once too.

- **Import from `~/.ssh/config`** — next to New connection in the hosts drawer, and on the empty state. Each host is resolved the way OpenSSH resolves it, so a trailing `Host *` supplies defaults while a specific block overrides them. Wildcards, `Match` blocks and `Include` lines are listed as skipped, with the reason. An `IdentityFile` selects public-key auth and carries the path over.
- **Import & export** — a new Settings panel writes every host, its tunnel rules and optionally your settings to one file, and reads one back with a checkbox per host. Passwords and key passphrases stay in the OS keychain and are never written to the file; both sides say which hosts will ask for one again. Importing only adds — a host already saved at the same address is flagged and starts unchecked.
- **Pick several hosts** — Ctrl-click to pick, Shift-click to span, then delete the batch with one confirmation. With nothing picked the drawer behaves exactly as before.
- **Deleting a host takes its tunnel rules with it.** Those rules were being left in the database where nothing could reach them again.
