SSH port-forwarding (tunnels) is now a first-class feature. You can configure persistent tunnel rules per host, import them from an SSH command, and export the command back with one click.

- **Tunnel rules per host** — add `-L` forwarding rules on the Tunnels tab of any host. Rules are saved to the database and auto-opened on connect based on the host's connection mode (Terminal only / Terminal + Tunnels / Tunnels only).
- **SSH import** — paste a full SSH command (e.g. `ssh -L 5432:db:5432 user@host`) into the import bar; multiple `-L` flags are parsed at once and added as rules in one step.
- **SSH export** — click any rule row to expand it and see the equivalent SSH command, with a Copy button.
- **LAN sharing toggle** — each rule has a switch to bind `0.0.0.0` instead of `127.0.0.1`, making the forwarded port reachable from other devices on your local network.
- **Live tunnel panel** — the Tunnels tab on an active session shows tunnel status in real time and lets you toggle or add session-only rules without editing the host.
