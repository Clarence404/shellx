# shellx v0.29.3

Serial terminals get the two controls that matter when a device stays silent: local echo and a choice of line ending. Both sit in the terminal header and can be flipped live, mid-session, until the device answers.

- **Local echo.** A per-session toggle prints what you type — raw serial rarely echoes, so this is what makes a mute device usable. Backspace erases and Enter advances a line on screen.
- **Line ending.** Choose what the Enter key sends on the wire — CR, LF, CRLF, or nothing — to match whatever the device expects. Defaults to CR; your choice survives a reconnect.
- **Clearer refresh.** The port rescan result is now a flashing pill ("Scanning…" → "Found N · time") so a rescan is obvious even when the port list is unchanged.
