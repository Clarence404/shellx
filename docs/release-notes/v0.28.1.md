# shellx v0.28.1

Fixes the Linux build. Drag-out had broken compilation on Linux since v0.24, so no Linux packages (AppImage / deb / rpm) shipped for several releases — this release restores them. Same features as v0.28.0 everywhere else.

- **Linux packages are back.** The drag-out feature now hands the GTK backend the window handle it expects; AppImage, deb and rpm build again.
- No functional changes on Windows or macOS.
