# ShellX v0.10.0

Local terminals arrive: open a shell on your own machine right next to your SSH tabs. The Tunnels panel gets a full UX pass — drag-to-reorder, cleaner forms, safer deletes — and the file browser's breadcrumb now has a clickable root.

- **Local terminal** — the `+` menu can now open a local shell tab (PowerShell by default on Windows; pick any shell in Settings → Terminal). Local tabs sit alongside SSH tabs with the same fonts, themes, and shortcuts.
- **Tunnels panel UX** — drag rules to reorder them (the order persists), add/edit forms with labeled fields, delete requires a second confirming click, and the SSH command line stays on one line with a Copy → Copied feedback.
- **Edit host → Tunnels tab** — larger, two-line rule rows and a readable form layout; expanding a rule scrolls its details into view.
- **File browser** — POSIX paths show a standalone `/` chip in the breadcrumb; click it to jump straight to the root directory.
- **Clearer status at a glance** — green dots mean connected (tabs and host list), the host belonging to the active tab stays highlighted in the sidebar, and rail / section labels are brighter.
