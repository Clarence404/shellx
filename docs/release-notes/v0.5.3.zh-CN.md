## 亮点

- Settings → Appearance 现在可以调**系统字体族**和**字号**
- 主题精简为 Warm Minimal + Warm Light；`ocean`/`forest` 旧值自动迁移
- 标签栏溢出控件：chevron 滚动 + tab-list 下拉 + 滚轮横滚 + tab 右键 Close all/left/right
- Terminal 边距在浅色/深色主题下现在保持一致
- 已关闭的会话不再出现在 RemotePane 主机选择器里

## Settings

- **系统字体大小**（Appearance → INTERFACE）——新增滑块（11–16 px），同时缩放所有 sans UI 元素：tabs、侧栏行、Settings 标签、主机列表、右键菜单、Terminal | Files 切换、按钮。
- **Appearance 面板**重构为 `INTERFACE` 和 `TERMINAL` 两个分组；字体族 + 字号在同一行。
- **主题精简**——下线了 Ocean 和 Forest。只保留 **Warm Minimal** 和 **Warm Light**。`settings.json` 里旧的 `ocean`/`forest` 加载时自动回落到 Warm Minimal。
- Reset to defaults 和所有右键菜单条目都跟随系统字体大小。

## 标题栏和标签页

- **溢出控件** ——当 tab 超出标题栏宽度时，右端出现紧凑的 `‹ › ≡` 组合。chevron 滚动 tab 条；列表图标打开可滚动的完整 tab 下拉，每行都能关闭。
- 标签条支持**滚轮横向滚动**；原生滚动条隐藏，pill 不再被裁。
- **tab 右键** → `Close N to the left` / `Close N to the right` / `Close all`（danger）。
- 用 `Ctrl+Tab` 切换 tab 时，选中的 tab 自动滚动到可视区域。
- 标签栏控件组和 min / max / close 之间保留 24 px 拖拽间距。

## 修复

- **Terminal 边距** ——浅色主题下，深色终端画布周围不再出现白色边缘。容器背景固定为终端自身的主题背景色，两个主题下表现一致。
- **主机选择器里的已关闭会话** ——RemotePane 下拉不再列出已关闭的 quick-connect 会话。
- **失效的 `rightHost`** ——tab 关闭后，RemotePane 会重置为 "Pick a host"，不会残留失效 id 或渲染幽灵 `/root` 面包屑。

## 底层

- 新增 `Settings.systemFontSize: u32`；v0.5.3 之前的 `settings.json` 通过 serde 默认值 13 无缝加载。
- 新的 `--font-ui-size` CSS 自定义属性驱动本次重构的所有 sans chrome 字号。
- Rust lib：31/31 测试通过。Vitest：106/106 通过。
