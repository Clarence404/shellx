# shellx v0.28.0

Command completion in the terminal, WindTerm-style: type at a prompt and a dropdown under the cursor offers your own command history alongside a built-in command dictionary. Local only — nothing is installed on your servers, and lines that look like they carry secrets are never recorded.

- **Completion dropdown.** Two characters in, prefix matches appear under the cursor: `h` rows are commands you've actually run on that host (recorded locally at Enter, most-used first), `c` rows come from a bundled dictionary of ~280 common commands. The typed prefix is bold; eight rows at most.
- **Keys that don't fight the shell.** ↑/↓ highlight, Tab accepts, and Enter accepts only after an explicit ↑/↓ — an un-navigated Enter runs the line you typed, exactly as before. Esc closes; every other key passes straight through, and the list steps aside for Tab completion, arrow-key editing, and full-screen apps like vim.
- **Private by construction.** History lives in the local database, keyed per host. Lines containing password-like patterns (and lines starting with a space, the bash convention) are never stored. Settings → Advanced has the on/off switch — off also stops recording — and a Clear-history button.
