# v0.18.3 — tunnels stay put across the rail

Running tunnels now stay visible and controllable no matter where the rail goes, and rules marked autostart open when shellx starts rather than when you first open the Tunnels view.

- **Tunnels survive navigation** — switch to Hosts, Files or Settings and back: every running rule still reads Running, and Stop still stops it.
- **Autostart at launch** — autostart rules dial their host as soon as the app is up, with no visit to the Tunnels view needed.
