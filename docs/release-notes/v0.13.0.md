# ShellX v0.13.0

Paste a full `ssh` command and the whole connection dialog fills itself in — target, port, key file, and tunnel rules. Forms also validate required fields now.

- **Smarter SSH import** — pasting a command like `ssh -i ~/.ssh/id_ed25519 -p 2222 -L 5432:db:5432 user@host` into the Tunnels import bar now fills the Basic tab too: `user@host` → username and host, `-p` → port, `-i` → switches to key-file auth with that key selected.
- **Required-field validation** — Host, Port, and Username are marked with `*`; leaving one empty shows a red border and hint, and Port validates 1–65535 before Save enables.
- **Polish** — tab titles truncate at the same width as the host sidebar, and the passphrase labels are fully translated in Chinese mode.
