# shellx v0.13.1

The copied SSH command is now a faithful equivalent of the tunnel shellx opens, and the Files-view host picker handles long names cleanly.

- **Accurate SSH export** — the command shown on a tunnel rule now includes `-i <key file>` for key-auth hosts, `-p` for non-default ports, and the `0.0.0.0:` bind prefix when LAN sharing is on — paste it into any terminal and it opens the same tunnel.
- **Files host picker** — the dropdown is fixed at sidebar width; long host names truncate with a tooltip instead of wrapping, and its labels are fully translated.
