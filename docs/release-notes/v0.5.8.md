## Highlights

- **Files font size — independent slider.** New `--font-files-size` CSS variable, its own setting in Appearance, and a live preview mock (folder + `.log` + `.json` + `.rs` rows) matching the real FileRow layout. Independent of the System font slider so cranking file rows doesn't inflate every other density-sized element.
- **Right-click menu flip.** `HostContextMenu` measures itself on mount and flips upward / leftward when it would spill past the viewport edge. Every file-row / empty-area / hosts-drawer menu benefits automatically.
- **PaneSplitter min-width guard.** Neither pane can be dragged below 200 px — hard clamp during drag prevents crushing the toolbar / breadcrumb into an unusable strip.
- **Unified size ranges.** `SYSTEM_FONT_SIZE_MAX` 16 → 18 so System / Files sliders share the identical 11-18 range. Equal values (e.g. 13 px) now put both thumbs at the same track position.

## Appearance panel restructure

- Two-column grid layout: fixed 110 px label column + 1fr control column, so labels + controls sit on the same line instead of stacking.
- Section headers upgraded to `text-1` + weight 600 + `--border-hi` underline — visibly separates Interface / System font / Files / Terminal.
- New **System font** section (was buried inside Interface) with Family / Size rows split apart, matching the Terminal section's layout.
- Every inline control (select / slider / segmented) uses `width: 320px` so right edges line up across the panel. Previews stay wider by design.
- Theme cards compacted (min-width 120 → 96, smaller swatch strip) so the top of the panel doesn't dominate the viewport.
