# v0.14.1

Two targeted fixes on top of v0.14.0.

- **SSH tunnel import — 4-part `-L` format** — pasting a command like `ssh -L 0.0.0.0:5432:db:5432 user@host` now correctly extracts the tunnel rule. Previously only the 3-part form (`-L port:host:port`) was recognised; the 4-part form with a bind address was silently skipped ("未找到 -L 规则").
- **Brand rename** — the app name is now consistently "ShellX" (capital X) throughout the UI, window title, and release assets.
