# v0.21.1 — Pane follow-ups

Two things that turned up while living with split panes: a pane could get stuck on a view with no way back, and two panes side by side gave no clue which tab was which.

- **Every pane has a way out** — the Monitor tab while it waits for its first sample, on a host it can't monitor at all, and the file browser before its first listing now keep their header row, so Terminal / Files / Tunnels / Monitor stays reachable from inside the pane.
- **Numbered panes** — split, each pane header and its tab wear the same number, and both fill with the accent on the focused one. Click a pane and its tab lights up.
- **A real waiting state** — the Monitor tab says what it is waiting for and when the next sample is due instead of one dim centred line.
