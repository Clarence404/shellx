# v0.14.3

Fixes local terminal shell selection so all built-in shells open reliably.

- **Shell auto-detection** — the shell picker now queries the system at startup and lists only shells that are actually installed. cmd and PowerShell 5 always appear; PowerShell 7 and WSL show up only when present.
- **Absolute path resolution** — cmd.exe, powershell.exe, and wsl.exe are resolved to their full `%SystemRoot%` paths before spawning, so they open correctly even when their directories are absent from the child process PATH.
- **Custom shell picker** — selecting "Custom path…" now shows a text field for manual entry alongside a Browse button that opens a native file picker, so you can navigate to any shell executable instead of typing the path by hand.
