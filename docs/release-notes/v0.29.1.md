# shellx v0.29.1

Serial port discovery now sees virtual ports. Ports whose drivers register outside the standard Windows COM-port class — com0com null-modem pairs among them — appear in the Detected ports list, and the connection form accepts a hand-typed port name for anything discovery still can't see.

- **Virtual ports discovered.** Windows port scanning falls back to the system's SERIALCOMM registry, which lists every live serial port regardless of driver class.
- **Manual port entry.** The port dropdown in the serial connection form gains a "Type manually…" option for ports not present at save time.
