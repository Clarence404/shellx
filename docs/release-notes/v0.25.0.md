# shellx v0.25.0

The FTP view learned to feel fast on slow servers: directories are cached and the whole tree warms in the background over dedicated connections, so clicks open instantly once connected. The connection form takes WinSCP's shape, the transfer bar shows live speed and remaining time, and delete confirmations work again everywhere.

- **Instant navigation.** Visited directories open from cache and revalidate silently; the tree under the directory on screen warms in the background (up to two extra connections, EPSV first), and the connecting panel narrates its phases and hands over only when the first level is already cached.
- **WinSCP-shaped connection form.** Protocol and encryption as two dropdowns — FTPS is FTP's TLS option, the port follows the pick — anonymous login, and name / transfer mode / encoding / key auth under Advanced.
- **Transfer bar shows speed.** Live combined rate and remaining time (`12.4 MB/s · 58m 3s`) on the collapsed bar, on every surface.
- **Delete asks again.** File deletion and settings-reset confirmations had stopped confirming (the dialog turned async underneath); they now truly block until answered.
- **Small polish.** The remote pane header is a connection picker that works even before connecting, the FTP list's status dot matches the Hosts view, toolbar icons sit together, a refused directory answers with a clear dialog, and empty folders say so properly.
