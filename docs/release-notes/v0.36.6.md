A tunnel's copy button can now hand you the `ssh -L` command as well as the local address, and says which one it copied.

- **Copy the ssh command.** Right-click a tunnel's copy button for a choice of its local address or the equivalent `ssh -L` command — with the host's key, its port when it isn't 22, and in the form the Import button reads back.
- **See what was copied.** A toast shows the text that went to the clipboard, which matters for a command you are about to paste into a shell.
- **The copy button stays a copy button.** Using it no longer opens the rule's edit panel behind the menu.
