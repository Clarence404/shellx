Reconnecting a dropped session now shows that it is reconnecting, and the sidebar stops calling a disconnected host online.

- **A reconnecting tab says so.** Its dot turns blue and pulses while the session redials, instead of staying greyed out as though nothing happened. The tab is clickable throughout, so you can watch it come back.
- **Disconnected hosts go grey in the sidebar.** A host whose tab has dropped no longer shows a green dot or counts towards its group's "online" total until it is actually back.
