# shellx v0.26.0

Snippets: your own library of commands worth not retyping. Save a command once, call it anywhere with Ctrl+Shift+K — filter, Enter, and it lands on the terminal's input line. `${name}` blanks ask for their values with a live preview, and the library travels in your config bundle.

- **Snippet palette.** Ctrl+Shift+K (or the ⚡ button in the titlebar) opens your snippet library over any terminal. Type to filter by name or command; Enter puts the command on the input line, unexecuted — snippets marked "run on pick" press Enter for you and carry a ⏎ badge as a reminder.
- **Fill-in-the-blanks.** Write `${service}` (any name, Chinese works) inside a snippet and picking it asks for the values first, previewing the final command as you type.
- **Managed in place.** The same dialog creates, edits and deletes snippets — no separate settings page to hunt for.
- **Travels with your config.** Export / import bundles now carry the snippet library, deduplicated by content on import; bundles from older versions still load.
