## Highlights

- Activity rail widened with icon + label under each button — no more missed clicks
- Titlebar's empty tab-strip area is now a drag surface, whether or not tabs are open

## Rail

- `--rail-w` widened from 32 → 64 px. Each button is now an icon + label
  stacked vertically (Hosts / Files / Protocols / Settings), giving a
  comfortable ~40 × 44 click target instead of a 28 × 28 icon-only pill.
- Hover state uses a subtle `--border` tint so only the ACTIVE view still
  reads as accent-filled.

## Titlebar

- Empty area of the tab strip (between tabs, or the whole strip when zero
  tabs are open) is now a `data-tauri-drag-region`. Grabbing an empty
  patch drags the window on all three platforms.
- Tabs, `+` button, `‹ › ≡` chrome cluster, and window controls keep their
  interactive behaviour — the drag region defers to native click handlers.
