# shellx v0.11.0

The interface now speaks two languages: switch between English and 中文 in Settings and the whole app follows — no restart needed. Also ships nicer forms, safer long-label handling, and a fix for the release pipeline.

- **UI language switch** — Settings → Appearance → Language toggles the entire interface between English and Chinese, saved with your other settings. Previously mixed-language spots (auth buttons, tunnel forms, trusted servers) are now consistent in both.
- **Cleaner dialogs** — the New/Edit host dialog gains input placeholders, aligned section headings, and tunnel-rule forms whose buttons no longer overflow the card.
- **Long host labels handled** — tabs cap at a fixed width with a tooltip for the full name, the connecting screen keeps its title on one line, and labels are limited to 60 characters at input.
- **Trusted servers** — the list scrolls when the window is short instead of clipping rows.
- **Release pipeline** — installers build again (a config encoding issue broke the v0.10.0 installers; upgraders coming from v0.9.0 lose nothing — v0.11.0 includes everything from v0.10.0).
