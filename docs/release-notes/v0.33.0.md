# v0.33.0

The monitor's Containers tab now works for users who aren't in the `docker` group. If the daemon is reachable only through passwordless sudo, shellx uses it automatically; if it can't be reached at all, the tab explains how to fix it instead of hiding.

- **Docker via passwordless sudo** — when the monitored user can't talk to the Docker daemon directly but has NOPASSWD sudo for it, container stats are read through `sudo -n docker`. The Containers tab appears and fills in as usual, no group change needed.
- **A helpful hint instead of a blank** — if docker is installed but unreachable (no direct access and no passwordless sudo), the tab now shows what to add to sudoers rather than silently disappearing.
