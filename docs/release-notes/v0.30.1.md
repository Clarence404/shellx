# shellx v0.30.1

Text polish on the monitor's top bands, and one bit of clutter removed.

- **Clearer load band.** The 1/5/15-minute averages now sit side by side (0.03 · 0.01 · 0.00) with a single "1 / 5 / 15 min · N cores" caption instead of a tiny label before each number.
- **Labelled since-boot totals.** The cumulative figures are grouped under Network / Disk / CPU, so the ↓↑ and read/write numbers say what they are at a glance.
- **Less duplication.** The host strip's memory readout is gone — the RAM total already lives in the memory KPI, and now also in the ⓘ system-info popover.
