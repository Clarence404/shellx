## 亮点

- **RemotePane 断线面板** —— 关掉 SSH tab 后 Files 视图不再残留"closed"错乱态，改成一张卡片 + Reconnect / Pick different host 按钮
- **终端配色** —— 绿色改成沉稳的鼠尾草绿，`ls` 里 other-writable 目录（蓝字绿底）终于看得清了
- **删除已保存 host** 会级联清理它的活会话，并重置任何指向这些会话的 Files 面板
- **New SSH connection 表单** —— Field 标签和 checkbox 与标题同色阶，不再灰白难认
- **面包屑 `C:` 修复** —— 点击盘符实际跳到盘根

## Files / RemotePane

- **DisconnectedPanel** 替代旧的乱七八糟空列表：session 关闭/清除时显示主机名 + 拔插头图标 + `Reconnect`（已保存 host）或 `Pick different host`（quick-connect）按钮。Reconnect 用 keychain 里的凭据调 `openConnection`，RailFilesView 的 growth watcher 会把 `rightHost` 切到新 session id。
- **`setRightHost` 完整清态** —— 切主机时额外清除 `rightError` 和 `rightLoading`，前一会话遗留的 `closed` 错误串不再泄漏到新面板。
- **sftpRealpath fallback** —— 新连接的 SFTP 子通道尚未完成 russh 握手时可能瞬时报 `closed`；`setRightHost` 现在回落到 `/`，让 `loadRight` 负责报错语义，不再把瞬时错误钉在面板上。
- **`..` 行防护** —— reset 到 realpath 落定的空窗期内不再意外渲染。
- **HostDropdown** —— 当前 host session 非 active 时下拉按钮旁挂 `closed` 徽标；session 被 `useSessions` 清除后仍能显示原保存 host 名（fallback）。
- **面包屑盘符修复** —— path bar 点 `C:` 现在导航到盘根（`C:/`），不再被 Rust `canonicalize("C:")` 静默劫持到 shellx.exe 进程的 CWD（bare `C:` 在 Windows 上代表"C 盘的当前工作目录"）。

## Terminal

- **ANSI 绿系** 改成鼠尾草绿：`green: #a6e3a1 → #7c9c80`、`brightGreen: #b8ecb0 → #95b298`。原来的 pastel 绿在作为 `ls` `ow`/`tw` 目录背景色时几乎把蓝色前景字吃掉。

## 标题栏和标签页

- **tab 条空白部分现在是拖动面** —— 抓 tab 之间的空隙（或完全没有 tab 时的整条 strip）就能拖窗口。TabBar 外层加了 `flex: 1, minWidth: 0`，strip 完全填满 wrapper，之前 tab 右边到窗口按钮之间的不可拖空隙消失了。

## 功能列（Rail）

- **rail 标签跟随系统字体大小**（`calc(var(--font-ui-size) - 2px)`）—— `Hosts` / `Files` / `Protocols` / `Settings` 四个标签跟标签页、侧栏、主机列表等其他 sans chrome 一起缩放。

## Hosts 抽屉

- **空态自动隐藏** —— 没保存过任何 host 时抽屉整块不渲染。主区 EmptyState 已经放了大 `+ New connection` 按钮，空抽屉没意义，等第一次保存 host 后自动出现。
- **删除级联清理** —— 删除已保存 host 会关闭所有 `session.host_id` 匹配的活会话（清 Zustand 里的 tab），并且如果 Files 面板的 `rightHost` 指向这些会话中的任何一个，也会重置。防止悬空 tab 和幽灵 `/root` 面包屑。
- **连接后自动收抽屉** —— `addSession` 现在带 `drawerCollapsed: true`，新会话一 active 抽屉就折起，终端拿到全宽。

## HostForm（New SSH connection 对话框）

- Field 大写标签（`LABEL` / `HOST` / `PORT` / `USERNAME` / `PASSWORD`）从 `var(--text-3)`、fontSize 10 升级到 `var(--text-1)`、fontSize 11、`fontWeight: 500`，与对话框标题同级。
- Checkbox 行标签（`Save this host`、`Remember password`、`Forget stored password`）从 `var(--text-2)` 升级到 `var(--text-1)`。禁用态（无 keychain 或密码为空的 `Remember password`）保持 `var(--text-3)` 提示不可操作。
