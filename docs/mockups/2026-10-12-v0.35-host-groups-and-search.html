新建 SSH 连接

这是个能点的示意（数据是假的）

  • 点分组标题折叠 / 展开，折叠状态下次打开还在
  • 搜索框实时过滤；搜索时命中的分组自动展开，只留匹配的主机，命中字符高亮；Esc 清空，Enter 连接第一个匹配项
  • 右键主机 → 移动到分组（选已有分组，或「新建分组」）
  • 右键分组标题 → 重命名 / 解散分组（主机回到「未分组」，不会被删）
  • 点「＋ 新建连接」看表单里新增的「分组」栏：下拉里是已有分组，也可以直接打新名字，输入时下面会提示「加入已有分组」还是「将新建分组」；编辑主机的表单同样有这一栏
  • 已有的连接怎么归组：升级后所有现有主机都在「未分组」，行为和以前一模一样。归组有三条路——①右键单台 → 移动到分组；②Ctrl+点选多台，底部出现「移动 N 台到分组」，一次归好；③编辑表单里的「分组」栏。分组只是整理手段，不影响连接本身：已连的会话、标签页、隧道、文件面板都不会因为改分组而断开或变化
  • 没分组的主机排在最后，没有任何分组时列表长得和现在一样
  • 分组头上显示「总数 · 在线数」，一眼看出哪组有连着的机器
