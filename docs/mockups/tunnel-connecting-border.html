推荐组合：B（重连中 · 橙 sweep）+ E（首次连接 · 蓝 sweep）。
理由：
 · 方向 sweep = "正在推进"，比呼吸/蚁行更贴 "connecting" 的语义；
 · 颜色区分两种 pending：蓝 = 从零开始（正常），橙 = 有过失败正在恢复（需要用户注意）；
 · 一旦转为 connected 立刻收边框；一旦转为 failed 边框变红色 + 停止流动。
